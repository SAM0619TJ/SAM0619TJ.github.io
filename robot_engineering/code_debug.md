# Debug 策略
调试是软件开发过程中不可或缺的一部分。有效的调试策略可以帮助开发者快速定位和解决代码中的问题。以下是一些常用的调试方法和工具。

## In vscode

集成调试器：单步执行、断点、变量监视

### 基本调试步骤

- 在代码行号左侧点击，设置断点
- 使用调试面板启动调试会话
  ，使用“继续”、“单步执行”、“跳过”等按钮控制代码执行
- 监视变量和表达式的值，使用“变量”面板查看当前作用域内的变量值
- 使用调用堆栈查看函数调用路径，定位问题根源
- 条件断点：右键点击断点，设置条件表达式
- 日志断点：右键点击断点，选择“编辑断点”，添加日志消息
- 使用“调试控制台”查看输出和错误信息，帮助分析问题
- 使用“变量”面板查看当前作用域内的变量值，帮助理解程序状态
