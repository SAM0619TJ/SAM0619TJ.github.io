# 排序算法

> **一句话**：将元素按关键字排列；不同算法在稳定性、原地性、最坏时间上各有取舍。
>
> 关键词：`快排` `归并` `堆排序` `稳定` `原地`

## 速查卡

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| 冒泡 | O(n²) | O(n²) | O(1) | 是 |
| 选择 | O(n²) | O(n²) | O(1) | 否 |
| 插入 | O(n²) | O(n²) | O(1) | 是 |
| 快排 | O(n log n) | O(n²) | O(log n) 栈 | 否 |
| 归并 | O(n log n) | O(n log n) | O(n) | 是 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 否 |
| 计数/基数 | O(n+k) | O(n+k) | O(k) | 是 |

---

## 评价维度

- **稳定性**：相等元素排序后相对顺序不变
- **原地**：额外空间 O(1)（不含递归栈）
- **自适应**：近乎有序时是否更快（插入排序是）

### STL

```cpp
#include <algorithm>
std::vector<int> v = {3,1,4,1,5};
std::sort(v.begin(), v.end());                    // 默认升序
std::sort(v.begin(), v.end(), std::greater<int>()); // 降序
```

`std::sort` 通常为 IntroSort（快排 + 堆排 + 插入），平均 O(n log n)。

## 冒泡排序

相邻比较交换，大元素逐步「冒泡」到末尾。

```cpp
void bubbleSort(std::vector<int>& a) {
    int n = static_cast<int>(a.size());
    for (int i = 0; i < n - 1; ++i)
        for (int j = 0; j < n - 1 - i; ++j)
            if (a[j] > a[j + 1]) std::swap(a[j], a[j + 1]);
}
```

可优化：一轮无交换则提前结束。

---

## 选择排序

每轮选最小放前面。

```cpp
void selectionSort(std::vector<int>& a) {
    int n = static_cast<int>(a.size());
    for (int i = 0; i < n; ++i) {
        int mn = i;
        for (int j = i + 1; j < n; ++j)
            if (a[j] < a[mn]) mn = j;
        std::swap(a[i], a[mn]);
    }
}
```

交换次数少，但不稳定。

---

## 插入排序

维护有序前缀，逐个插入。小数据、近乎有序时高效。

```cpp
void insertionSort(std::vector<int>& a) {
    int n = static_cast<int>(a.size());
    for (int i = 1; i < n; ++i) {
        int key = a[i], j = i - 1;
        while (j >= 0 && a[j] > key) { a[j + 1] = a[j]; --j; }
        a[j + 1] = key;
    }
}
```

---

## 快速排序

分治：选 pivot，小于放左、大于放右，递归。

```cpp
void quickSort(std::vector<int>& a, int lo, int hi) {
    if (lo >= hi) return;
    int pivot = a[hi], i = lo;
    for (int j = lo; j < hi; ++j)
        if (a[j] < pivot) std::swap(a[i++], a[j]);
    std::swap(a[i], a[hi]);
    quickSort(a, lo, i - 1);
    quickSort(a, i + 1, hi);
}
```

最坏 O(n²)（已有序 + 烂 pivot）；工程上随机 pivot 或三数取中。

## 归并排序

分半 → 排序 → 合并，稳定 O(n log n)，需 O(n) 辅助数组。

```cpp
void merge(std::vector<int>& a, int lo, int mid, int hi, std::vector<int>& tmp) {
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi)
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    while (i <= mid) tmp[i++] = a[i++];
    while (j <= hi) tmp[k++] = a[j++];
    for (int t = lo; t <= hi; ++t) a[t] = tmp[t];
}

void mergeSort(std::vector<int>& a, int lo, int hi, std::vector<int>& tmp) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(a, lo, mid, tmp);
    mergeSort(a, mid + 1, hi, tmp);
    merge(a, lo, mid, hi, tmp);
}
```

链表排序常用归并（O(1) 额外空间若迭代实现）。

## 选型建议

| 场景 | 选择 |
|------|------|
| 一般数组 | `std::sort` / 快排 |
| 需要稳定 | 归并 |
| 链表 | 归并 |
| 几乎有序 | 插入 |
| Top-K | 堆，不是全排序 |
| 整数范围小 | 计数 |

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 快排最坏数据 | 随机化 pivot |
| 归并忘记拷贝回原数组 | merge 后写回 `a` |
| 认为堆排序稳定 | 不稳定 |
| 对小数组用快排 | 插入排序常更快（阈值 ~16） |
