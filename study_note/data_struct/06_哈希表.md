# 哈希表

> **一句话**：通过哈希函数将键映射到桶槽，实现均摊 O(1) 的增删查。
>
> 关键词：`unordered_map` `哈希冲突` `链地址` `装载因子`

## 问题建模

需要**快速**根据键（key）存取值（value），且键分布未知。

生活类比：字典按拼音首字母分区，先定位区再细查——哈希表用函数直接算「区号」。

---

## 核心概念

| 概念 | 说明 |
|------|------|
| 哈希函数 | `hash(key) → 桶索引` |
| 桶（bucket） | 存储键值对的槽位 |
| 冲突 | 不同 key 映射到同一桶 |
| 装载因子 | $\alpha = n / m$（元素数 / 桶数） |

好的哈希函数：均匀分布、计算快、确定性。

---

## STL 用法（C++17）

```cpp
// === File: hash_map.cpp ===
#include <unordered_map>
#include <string>

std::unordered_map<std::string, int> freq;

/* 插入 / 更新 */
freq["apple"] = 3;
freq.insert({"banana", 2});

/* 查询 */
if (freq.count("apple")) {
    int v = freq["apple"];
}
auto it = freq.find("apple");
if (it != freq.end()) {
    int v = it->second;
}

/* 删除 */
freq.erase("banana");

/* 遍历 */
for (const auto& [key, val] : freq) {  // C++17 结构化绑定
    // ...
}
```

自定义键需特化 `std::hash` 或提供哈希仿函数。

## 冲突处理

### 1. 链地址法（Separate Chaining）

每个桶存**链表**（或树），冲突元素串在同一桶。

```
桶 0: (k1,v1) -> (k5,v5)
桶 1: (k2,v2)
桶 2: null
```

- 优点：实现简单，删除方便，装载因子可 > 1
- 缺点：指针开销，缓存不如开放寻址

`std::unordered_map` 采用类似思路；链表过长时可能树化（实现相关）。

### 2. 开放寻址法（Open Addressing）

冲突时在表中**探测**下一个空槽（线性探测、二次探测等）。

- 优点：缓存友好，无指针
- 缺点：删除复杂，装载因子需 < 1

## 简化手写实现（链地址）

```cpp
class HashMap {
    static const int CAP = 10007;  // 质数桶数
    std::vector<std::vector<std::pair<int,int>>> buckets_;
public:
    HashMap() : buckets_(CAP) {}

    int hash(int key) const {
        return (key % CAP + CAP) % CAP;
    }

    void put(int key, int val) {
        int idx = hash(key);
        for (auto& [k, v] : buckets_[idx]) {
            if (k == key) { v = val; return; }
        }
        buckets_[idx].emplace_back(key, val);
    }

    int get(int key, int default_val = -1) const {
        int idx = hash(key);
        for (const auto& [k, v] : buckets_[idx])
            if (k == key) return v;
        return default_val;
    }
};
```

## 扩容

装载因子过高 → 冲突增多 → 性能退化。通常 $\alpha > 0.75$ 时**扩容**（桶数翻倍）并**重哈希**所有元素，均摊仍 O(1)。

## 典型应用

| 场景 | 用法 |
|------|------|
| 两数之和 | 边遍历边 `find(target - x)` |
| 频次统计 | `unordered_map<T,int>` |
| 去重 | `unordered_set<T>` |
| LRU | 哈希 + 双向链表 |

## 例题：两数之和

```cpp
std::vector<int> twoSum(const std::vector<int>& nums, int target) {
    std::unordered_map<int, int> idx;  // 值 -> 下标
    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        int need = target - nums[i];
        if (idx.count(need))
            return {idx[need], i};
        idx[nums[i]] = i;
    }
    return {};
}
```

## `unordered_set` 与自定义哈希

```cpp
#include <unordered_set>

std::unordered_set<int> seen;
seen.insert(42);
if (seen.count(42)) { /* 存在 */ }
```

组合键可用 `struct PairHash` 或 `boost::hash_combine` 风格：

```cpp
struct PairHash {
    size_t operator()(const std::pair<int,int>& p) const {
        return std::hash<long long>()(
            (static_cast<long long>(p.first) << 32) | p.second);
    }
};
std::unordered_map<std::pair<int,int>, int, PairHash> grid;
```

## 开放寻址（了解）

线性探测：冲突时探查 `(i+1) % m`。删除需标记 tombstone。工程上 `unordered_map` 细节由标准库实现。

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 用 `map` 当哈希表 | O(log n) 红黑树；要 O(1) 用 `unordered_map` |
| 自定义类型未提供 hash | 特化 `std::hash` 或 lambda |
| `operator[]` 自动插入 | 只查询用 `find` / `count` |
| 忽略最坏 O(n) | 竞赛数据可接受；工程需好的哈希与扩容 |
