# 字符串匹配（KMP）

> **一句话**：利用已匹配信息跳过无效比较，将朴素匹配从 O(nm) 降到 O(n+m)。
>
> 关键词：`KMP` `next` `前缀函数` `子串`

[← 数据结构索引](study_note/data_struct/index.html) · [速查表](md.html?file=study_note/data_struct/速查.md)

## 速查卡

| 算法 | 时间 | 空间 |
|------|------|------|
| 朴素匹配 | O(nm) | O(1) |
| KMP | O(n+m) | O(m) |
| 哈希（Rabin-Karp） | 平均 O(n+m) | O(1) |

n = 文本长，m = 模式长。

---

## 朴素匹配

```cpp
int naiveFind(const std::string& text, const std::string& pat) {
    int n = static_cast<int>(text.size()), m = static_cast<int>(pat.size());
    for (int i = 0; i <= n - m; ++i) {
        int j = 0;
        while (j < m && text[i + j] == pat[j]) ++j;
        if (j == m) return i;
    }
    return -1;
}
```

## KMP 核心：next（前缀函数）

`next[i]` = 模式 `pat[0..i]` 的最长真前后缀相等长度。

```cpp
// === File: kmp.cpp ===
#include <string>
#include <vector>

std::vector<int> buildNext(const std::string& pat) {
    int m = static_cast<int>(pat.size());
    std::vector<int> next(m, 0);
    for (int i = 1, j = 0; i < m; ++i) {
        while (j > 0 && pat[i] != pat[j]) j = next[j - 1];
        if (pat[i] == pat[j]) ++j;
        next[i] = j;
    }
    return next;
}

int kmpFind(const std::string& text, const std::string& pat) {
    auto next = buildNext(pat);
    int n = static_cast<int>(text.size()), m = static_cast<int>(pat.size());
    for (int i = 0, j = 0; i < n; ++i) {
        while (j > 0 && text[i] != pat[j]) j = next[j - 1];
        if (text[i] == pat[j]) ++j;
        if (j == m) return i - m + 1;
    }
    return -1;
}
```

失配时 `j = next[j-1]`，文本指针 `i` 不回溯。

## 与数据结构关系

- `next` 数组本身是对**模式串结构**的预处理
- 可视为对「前缀集合」的压缩信息，与 Trie 前缀思想相关

| 算法 | 特点 |

| Rabin-Karp | 滚动哈希，多模式 |
| Z-function | 与 KMP 等价信息不同形式 |

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| next 定义搞错 | 明确「真前后缀」不含全长 |
| 失配时 i-- | KMP 文本指针只增 |
| 空模式 | 特判返回 0 |
| 与正则混淆 | KMP 纯字面匹配 |
