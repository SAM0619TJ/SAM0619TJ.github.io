# 栈与队列

> **一句话**：栈后进先出（LIFO），队列先进先出（FIFO）。
>
> 关键词：`stack` `queue` `deque` `LIFO` `FIFO`

[← 数据结构索引](study_note/data_struct/index.html) · [速查表](md.html?file=study_note/data_struct/速查.md)

---

## 速查卡

| 结构 | 规则 | 核心操作 | 时间复杂度 |
|------|------|----------|------------|
| 栈 | LIFO | push / pop / top | 均 O(1) |
| 队列 | FIFO | push / pop / front | 均 O(1) |
| 双向队列 | 两端可操作 | pushFront / pushBack 等 | 均 O(1) |

---

## 栈

类比一摞盘子：只能从顶部放入或取出。

### 操作 API

| 方法 | 含义 | 复杂度 |
|------|------|--------|
| `push(x)` | 入栈 | O(1) |
| `pop()` | 出栈 | O(1) |
| `top()` | 访问栈顶 | O(1) |
| `empty()` | 是否为空 | O(1) |

### STL 用法

```cpp
// === File: stack.cpp ===
#include <stack>

std::stack<int> stk;
stk.push(1);
stk.push(3);
stk.push(2);

int top_val = stk.top();  // 2
stk.pop();                // 无返回值
bool empty = stk.empty();
int size = static_cast<int>(stk.size());
```

### 基于数组实现

```cpp
class ArrayStack {
    std::vector<int> data_;
public:
    void push(int x) { data_.push_back(x); }
    void pop() {
        if (data_.empty()) throw std::out_of_range("栈为空");
        data_.pop_back();
    }
    int top() const {
        if (data_.empty()) throw std::out_of_range("栈为空");
        return data_.back();
    }
    bool empty() const { return data_.empty(); }
    int size() const { return static_cast<int>(data_.size()); }
};
```

### 基于链表实现（头作栈顶）

```cpp
class LinkedStack {
    ListNode* top_ = nullptr;
public:
    void push(int x) {
        auto* node = new ListNode(x);
        node->next = top_;
        top_ = node;
    }
    int pop() {
        if (!top_) throw std::out_of_range("栈为空");
        int val = top_->val;
        ListNode* tmp = top_;
        top_ = top_->next;
        delete tmp;
        return val;
    }
};
```

### 典型应用

- 括号匹配、表达式求值
- 浏览器后退、撤销/重做
- DFS 迭代、函数调用栈

## 队列

类比排队：尾部入队，头部出队。

### STL 用法

```cpp
// === File: queue.cpp ===
#include <queue>

std::queue<int> q;
q.push(1);
q.push(3);
q.push(2);

int front_val = q.front();  // 1
q.pop();
bool empty = q.empty();
```

### 基于链表实现（头删尾插）

```cpp
class LinkedQueue {
    ListNode* front_ = nullptr;
    ListNode* rear_ = nullptr;
    int size_ = 0;
public:
    void push(int x) {
        auto* node = new ListNode(x);
        if (!rear_) front_ = rear_ = node;
        else { rear_->next = node; rear_ = node; }
        ++size_;
    }
    int pop() {
        if (!front_) throw std::out_of_range("队列为空");
        int val = front_->val;
        ListNode* tmp = front_;
        front_ = front_->next;
        if (!front_) rear_ = nullptr;
        delete tmp;
        --size_;
        return val;
    }
};
```

### 基于数组（环形队列）

用 `front` 指针 + 取模实现首尾相连，避免头删 O(n) 移动。

```cpp
class ArrayQueue {
    std::vector<int> buf_;
    int front_ = 0, size_ = 0;
    int cap() const { return static_cast<int>(buf_.size()); }
    int index(int i) const { return (i + cap()) % cap(); }
public:
    explicit ArrayQueue(int capacity) : buf_(capacity) {}
    void push(int x) {
        if (size_ == cap()) throw std::out_of_range("队列已满");
        buf_[index(front_ + size_)] = x;
        ++size_;
    }
    int pop() {
        if (size_ == 0) throw std::out_of_range("队列为空");
        int val = buf_[front_];
        front_ = index(front_ + 1);
        --size_;
        return val;
    }
};
```

### 典型应用

- BFS 层次遍历
- 任务调度、消息队列
- 滑动窗口（配合 `deque`）

## 双向队列 `deque`

两端均可入队出队，C++17 用 `std::deque`。

```cpp
#include <deque>

std::deque<int> dq;
dq.push_back(1);
dq.push_front(2);
dq.pop_back();
dq.pop_front();
```

适合「单调队列」、需要两端操作的场景。

---

## 实现对比

| 维度 | 数组栈 | 链表栈 |
|------|--------|--------|
| 时间 | 缓存好，均摊快 | 稳定 O(1)，指针开销 |
| 空间 | 可能预留容量 | 每节点多指针 |

队列同理：工程里直接用 `std::queue` / `std::deque`。

## 例题：有效括号

```cpp
bool isValid(const std::string& s) {
    std::stack<char> stk;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') stk.push(c);
        else {
            if (stk.empty()) return false;
            char top = stk.top(); stk.pop();
            if ((c == ')' && top != '(') ||
                (c == ']' && top != '[') ||
                (c == '}' && top != '{')) return false;
        }
    }
    return stk.empty();
}
```

## 易错点

| 易错 | 正确做法 |
|------|----------|
| `stack`/`queue` 遍历 | 不支持迭代器，只能逐 pop |
| `pop()` 返回值 | STL 的 pop 无返回值，先 top 再 pop |
| 用 `vector` 头删模拟队列 | O(n)，应使用 `queue` 或环形数组 |
| 忘记判空 | pop/top 前检查 `empty()` |
