## 实现选型口诀

- 默认序列 → `vector`
- 两端操作 → `deque`
- 快速查找 → `unordered_map`
- 有序键 → `map`
- 最值 / Top-K → `priority_queue`
- 前缀词 → Trie
- 区间统计 → 树状数组 / 线段树
- 连通 → 并查集
- 有序可手写 → 跳表或 `map`
- 2D 范围/地图 → 四叉树
- 最近邻 → KD-tree
- 光追/3D 拾取 → BVH + AABB
- 室内绘制序 → BSP
