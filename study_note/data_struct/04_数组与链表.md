# 数组与链表

> **一句话**：数组连续存储、随机访问快；链表分散存储、插删灵活。
>
> 关键词：`vector` `链表` `随机访问` `头插` `尾插` `缓存`

## 速查卡

| 操作 | 数组 / `vector` | 链表 |
|------|-------------------|------|
| 随机访问 | O(1) | O(n) |
| 头插 | O(n) | O(1) |
| 尾插 | 均摊 O(1) | O(1)（有尾指针） |
| 按值查找 | O(n) | O(n) |
| 缓存友好 | 是 | 否 |

## 数组

相同类型元素存放在**连续内存**，通过索引访问。

$$\text{地址}(i) = \text{首地址} + i \times \text{元素大小}$$

### STL 用法（C++17）

```cpp
// === File: array.cpp ===
#include <vector>

/* 初始化 */
std::vector<int> nums = {1, 3, 2, 5, 4};
std::vector<int> empty_vec;

/* 访问 */
int x = nums[2];        // 不检查边界
int y = nums.at(2);     // 越界抛异常

/* 尾插 / 尾删 */
nums.push_back(6);      // 均摊 O(1)
nums.pop_back();        // O(1)

/* 大小 */
int n = static_cast<int>(nums.size());
bool ok = nums.empty();
```

### 中间插入（手写思路）

```cpp
/* 在索引 index 处插入 num，时间 O(n) */
void insert(std::vector<int>& nums, int index, int num) {
    nums.push_back(0);  // 扩一位
    for (int i = static_cast<int>(nums.size()) - 1; i > index; --i)
        nums[i] = nums[i - 1];
    nums[index] = num;
}
```

## 链表

节点分散存储，每个节点含**值** + **指向下一节点的指针**。

### 节点定义

```cpp
// === File: linked_list.cpp ===
struct ListNode {
    int val;
    ListNode* next;
    explicit ListNode(int x) : val(x), next(nullptr) {}
};
```

### 头插（O(1)）

```cpp
void pushFront(ListNode*& head, int val) {
    auto* node = new ListNode(val);
    node->next = head;
    head = node;
}
```

### 遍历与删除

```cpp
/* 删除首个值为 target 的节点，O(n) */
void remove(ListNode*& head, int target) {
    ListNode dummy(0);
    dummy.next = head;
    ListNode* prev = &dummy;
    while (prev->next) {
        if (prev->next->val == target) {
            ListNode* tmp = prev->next;
            prev->next = prev->next->next;
            delete tmp;
            break;
        }
        prev = prev->next;
    }
    head = dummy.next;
}
```

### 完整链表类（简化）

```cpp
class LinkedList {
    ListNode* head_ = nullptr;
    int size_ = 0;
public:
    ~LinkedList() {
        while (head_) {
            ListNode* tmp = head_;
            head_ = head_->next;
            delete tmp;
        }
    }
    void pushFront(int val) {
        auto* node = new ListNode(val);
        node->next = head_;
        head_ = node;
        ++size_;
    }
    int size() const { return size_; }
};
```

## 动态数组 `vector` vs 链表

| 维度 | `vector` | 链表 |
|------|----------|------|
| 随机访问 | O(1) | O(n) |
| 尾插 | 均摊 O(1) | O(1) |
| 中间插删 | O(n) | O(1)* |
| 内存 | 紧凑，可能预留容量 | 每节点额外指针 |
| 缓存 | 好 | 差 |

\* 已知节点指针时 O(1)。

**实践建议**：默认用 `vector`；只有频繁头插删、或节点本身就是对象引用时用链表。

## 典型应用

| 结构 | 场景 |
|------|------|
| 数组 | 矩阵、动态规划表、堆底层 |
| 链表 | LRU 缓存、多项式、图邻接表（链式） |
| `vector` | 绝大多数算法题、邻接表（推荐） |

## 例题

**问**：反转单链表（迭代）。

```cpp
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    while (head) {
        ListNode* nxt = head->next;
        head->next = prev;
        prev = head;
        head = nxt;
    }
    return prev;
}
```

## 双向链表

每个节点含 `prev` 和 `next`，头尾插删均为 O(1)（有头尾指针时）。

```cpp
struct DoublyListNode {
    int val;
    DoublyListNode *prev, *next;
    explicit DoublyListNode(int v) : val(v), prev(nullptr), next(nullptr) {}
};
```

应用：LRU 缓存、浏览器历史（见 [LRU](md.html?file=study_note/data_struct/15_LRU缓存.md)）。

## 环形链表

尾节点 `next` 指向头；判环用快慢指针。

```cpp
bool hasCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}
```

## `std::list` 与 `vector`

| | `vector` | `std::list` |
|---|----------|-------------|
| 缓存 | 好 | 差 |
| 中间插删 | O(n) 移动 | O(1) 有迭代器 |
| 竞赛 | **首选** | 少用 |

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 链表删除后未断开 `next` | 标准库风格应断开；做题逻辑正确即可 |
| `vector` 边遍历边 erase | 用索引回退或 erase 返回迭代器 |
| 裸指针泄漏 | 析构释放，或 `unique_ptr` |
| 认为链表插删总 O(1) | 查找位置 O(n) |
