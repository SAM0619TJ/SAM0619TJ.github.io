# 二分查找

> **一句话**：在有序序列上每次排除一半，O(log n) 定位目标。
>
> 关键词：`二分` `lower_bound` `upper_bound` `左闭右开`

[← 数据结构索引](study_note/data_struct/index.html) · [速查表](md.html?file=study_note/data_struct/速查.md)

## 速查卡

| 变体 | 含义 | STL |
|------|------|-----|
| 标准二分 | 找等于 target 的位置 | 手写 |
| 左边界 | 第一个 ≥ target | `lower_bound` |
| 右边界 | 第一个 > target | `upper_bound` |
| 插入点 | 保持有序的插入位置 | `lower_bound` |

前提：**有序**（或单调性可二分答案）。

---

## 标准模板（左闭右闭）

```cpp
// === File: binary_search.cpp ===
#include <vector>

int binarySearch(const std::vector<int>& a, int target) {
    int lo = 0, hi = static_cast<int>(a.size()) - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] == target) return mid;
        if (a[mid] < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}
```

`mid = lo + (hi - lo) / 2` 防 `lo+hi` 溢出。

## STL（C++17）

```cpp
#include <algorithm>
#include <vector>

std::vector<int> v = {1, 2, 2, 2, 5};
auto it = std::lower_bound(v.begin(), v.end(), 2);  // 第一个 >= 2
auto jt = std::upper_bound(v.begin(), v.end(), 2);  // 第一个 > 2
int count = static_cast<int>(jt - it);  // 2 的个数 = 3
```

## 左边界（第一个 ≥ target）

```cpp
int lowerBound(const std::vector<int>& a, int target) {
    int lo = 0, hi = static_cast<int>(a.size());
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < target) lo = mid + 1;
        else hi = mid;
    }
    return lo;  // 若 lo == n 则不存在
}
```

区间 **[lo, hi)** 左闭右开，`lo == hi` 时结束。

## 二分答案

问题未必有序数组，但答案具有**单调性**（如「最小可行速度」）。

```cpp
bool canFinish(const std::vector<int>& piles, int h, long long speed) {
    long long hours = 0;
    for (int p : piles) hours += (p + speed - 1) / speed;
    return hours <= h;
}

long long minSpeed(const std::vector<int>& piles, int h) {
    long long lo = 1, hi = 1e9;
    while (lo < hi) {
        long long mid = lo + (hi - lo) / 2;
        if (canFinish(piles, h, mid)) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
```

## 常见题型

| 题型 | 做法 |
|------|------|
| 搜索旋转排序数组 | 判断 mid 在哪一半有序 |
| 找峰值 | 二分比较 mid 与 mid+1 |
| 平方根 / 根号 | 二分实数或整数 |
| 最小化最大值 | 二分答案 + 判定 |

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| `while (lo < hi)` vs `<=` 混用 | 固定一种区间定义 |
| `mid` 溢出 | `lo + (hi-lo)/2` |
| 右边界 off-by-one | `upper_bound - 1` 才是最后一个等于 |
| 无序数组二分 | 先排序或二分答案 |
