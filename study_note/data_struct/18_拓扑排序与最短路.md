## 拓扑排序

有向无环图（DAG）的线性序，使得每条边 u→v 中 u 在 v 前面。

**应用**：课程表、编译依赖、任务调度。

### Kahn（入度 + 队列）

```cpp
// === File: topo.cpp ===
#include <vector>
#include <queue>

std::vector<int> topoSort(int n, const std::vector<std::vector<int>>& adj) {
    std::vector<int> indeg(n, 0);
    for (int u = 0; u < n; ++u)
        for (int v : adj[u]) ++indeg[v];

    std::queue<int> q;
    for (int i = 0; i < n; ++i)
        if (indeg[i] == 0) q.push(i);

    std::vector<int> order;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        order.push_back(u);
        for (int v : adj[u])
            if (--indeg[v] == 0) q.push(v);
    }
    return order.size() == n ? order : std::vector<int>{};  // 空表示有环
}
```

### DFS 版

DFS 完成时**逆序**入栈；或三色标记检测回边判环。

## Dijkstra

单源最短路径，边权 ≥ 0。用小顶堆每次取距离最小未确定顶点。

```cpp
#include <queue>
#include <vector>
#include <limits>

using ll = long long;
const ll INF = std::numeric_limits<ll>::max() / 4;

std::vector<ll> dijkstra(int n, int src,
    const std::vector<std::vector<std::pair<int,int>>>& adj) {
    std::vector<ll> dist(n, INF);
    dist[src] = 0;
    using P = std::pair<ll,int>;
    std::priority_queue<P, std::vector<P>, std::greater<P>> pq;
    pq.emplace(0, src);

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;
        for (auto [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.emplace(dist[v], v);
            }
        }
    }
    return dist;
}
```

**注意**：负权边用 Bellman-Ford / SPFA，不用 Dijkstra。

## 算法选型

| 问题 | 算法 |
|------|------|
| 无权最短路 | BFS |
| 非负权最短路 | Dijkstra |
| 负权边 | Bellman-Ford |
| 全源最短路（小 V） | Floyd O(V³) |
| 判 DAG / 排课 | 拓扑排序 |
| 最小生成树 | Kruskal + 并查集 |

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 有环仍输出拓扑序 | 判断 `order.size() == n` |
| Dijkstra 用于负权 | 会错 |
| 不判 `d > dist[u]` | 堆中过期条目重复松弛 |
| 混淆 BFS 层数与带权最短路 | 带权必须 Dijkstra |
