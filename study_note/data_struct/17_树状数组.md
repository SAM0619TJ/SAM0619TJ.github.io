# 树状数组（Fenwick Tree）

> **一句话**：用数组模拟树形结构，单点修改 + 前缀查询 O(log n)，代码比线段树短。
>
> 关键词：`BIT` `Fenwick` `lowbit` `前缀和`

[← 数据结构索引](study_note/data_struct/index.html) · [速查表](md.html?file=study_note/data_struct/速查.md)

---

## 速查卡

| 操作 | 复杂度 |
|------|--------|
| `add(i, delta)` 单点加 | O(log n) |
| `prefix(i)` 前缀和 [1..i] | O(log n) |
| 区间和 [l,r] | `prefix(r) - prefix(l-1)` |
| 空间 | O(n) |

1-based 下标最常用。

---

## lowbit

```cpp
int lowbit(int x) { return x & -x; }
```

`lowbit(i)` = i 二进制最低位 1 所代表的值，划分管辖区间长度。

---

## 实现

```cpp
// === File: fenwick.cpp ===
#include <vector>

class Fenwick {
    std::vector<long long> bit_;
    int n_;

public:
    explicit Fenwick(int n) : bit_(n + 1, 0), n_(n) {}

    void add(int i, long long delta) {
        for (; i <= n_; i += lowbit(i))
            bit_[i] += delta;
    }

    long long prefix(int i) const {
        long long sum = 0;
        for (; i > 0; i -= lowbit(i))
            sum += bit_[i];
        return sum;
    }

    long long range(int l, int r) const {
        return prefix(r) - prefix(l - 1);
    }

private:
    static int lowbit(int x) { return x & -x; }
};
```

从原数组构建：对每个 `a[i]` 调用 `add(i, a[i])`。

## 二维树状数组

矩阵子矩形和 + 单点修改：外层对行维护 BIT，或二维 BIT O(log² n)。

---

## 与线段树对比

| | 树状数组 | 线段树 |
|---|----------|--------|
| 代码量 | 短 | 长 |
| 前缀/区间和 | 优 | 可以 |
| 区间最值 | 需改写/线段树 | 自然 |
| 区间修改 | 需差分配合 | 懒标记 |

---

## 逆序对（应用）

归并 O(n log n) 或 BIT：从后往前，对每个 `a[i]` 查询已处理中 `< a[i]` 个数。

```cpp
long long invCount(std::vector<int>& a) {
    // 离散化后值域为 1..m
    Fenwick fw(m);
    long long ans = 0;
    for (int i = n - 1; i >= 0; --i) {
        ans += fw.prefix(rank[i] - 1);
        fw.add(rank[i], 1);
    }
    return ans;
}
```

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 0-based 直接套公式 | 转 1-based 或调整下标 |
| `prefix(0)` | 定义为 0 |
| 忘记离散化 | 值域大时压缩坐标 |
| 区间修改直接 BIT | 用差分 BIT 或线段树 |
