# 跳表（Skip List）

> **一句话**：多层有序链表 + 随机层高，期望 O(log n) 查找，实现比平衡树简单。
>
> 关键词：`跳表` `多层索引` `Redis` `有序结构`

## 速查卡

| 操作 | 期望复杂度 |
|------|------------|
| 查找 | O(log n) |
| 插入 | O(log n) |
| 删除 | O(log n) |
| 空间 | O(n) 期望 |

Redis 有序集合（ZSET）底层之一为跳表。

---

## 结构

- 底层：有序链表，包含所有元素
- 上层：随机抽取节点建立「快速路」
- 头节点层数 = 当前最大层数

查找：从顶层向右，不能超过目标；然后下降一层。

---

## 层高随机

每层晋升概率 p（常取 1/2 或 1/4），期望层数 O(log n)。

```cpp
// === File: skiplist.cpp ===
#include <random>
#include <vector>
#include <limits>

struct SkipNode {
    int val;
    std::vector<SkipNode*> forward;
    explicit SkipNode(int v, int level) : val(v), forward(level + 1, nullptr) {}
};

class SkipList {
    static constexpr int MAX_LEVEL = 16;
    static constexpr float P = 0.5f;
    SkipNode* head_;
    int level_;
    std::mt19937 rng_{std::random_device{}()};

    int randomLevel() {
        int lvl = 0;
        while ((float)rng_() / rng_.max() < P && lvl < MAX_LEVEL) ++lvl;
        return lvl;
    }

public:
    SkipList() : head_(new SkipNode(-1, MAX_LEVEL)), level_(0) {}

    SkipNode* search(int target) {
        SkipNode* cur = head_;
        for (int i = level_; i >= 0; --i) {
            while (cur->forward[i] && cur->forward[i]->val < target)
                cur = cur->forward[i];
        }
        cur = cur->forward[0];
        return (cur && cur->val == target) ? cur : nullptr;
    }

    void insert(int val) {
        std::vector<SkipNode*> update(MAX_LEVEL + 1, head_);
        SkipNode* cur = head_;
        for (int i = level_; i >= 0; --i) {
            while (cur->forward[i] && cur->forward[i]->val < val)
                cur = cur->forward[i];
            update[i] = cur;
        }
        int lvl = randomLevel();
        if (lvl > level_) {
            for (int i = level_ + 1; i <= lvl; ++i) update[i] = head_;
            level_ = lvl;
        }
        auto* node = new SkipNode(val, lvl);
        for (int i = 0; i <= lvl; ++i) {
            node->forward[i] = update[i]->forward[i];
            update[i]->forward[i] = node;
        }
    }
};
```

## 与平衡树对比

| | 跳表 | AVL/红黑树 |
|---|------|------------|
| 实现难度 | 较低 | 较高 |
| 范围查询 | 链表扫描 | 中序 |
| 并发 | 局部锁友好 | 旋转复杂 |
| STL | 无 | `map` |

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| `update` 数组未维护 | 每层记录前驱 |
| 层数不更新 | 插入更高层时抬 `level_` |
| 与哈希混淆 | 跳表维护**有序** |
