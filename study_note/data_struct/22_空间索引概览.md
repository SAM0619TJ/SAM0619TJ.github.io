## Broad phase 与 Narrow phase

```
物体 → AABB 粗测 → 空间索引（Quadtree / BVH）→ 候选对 → 窄相位（精确几何）
光线 → BVH 遍历 → 叶节点三角形相交 → 着色
```

- **Broad phase**：快速排除不可能相交的对
- **Narrow phase**：对候选对做 SAT、GJK 等精确检测

## 空间划分 vs 物体层次

| | Quadtree / KD-tree | BVH |
|---|-------------------|-----|
| 切分对象 | 空间区域 | 物体集合 |
| 大物体 | 可能占多格 | 单条树路径 |
| 动态更新 | 较难 | refit / 局部重建 |
