# 四叉树（Quadtree）

> **一句话**：将 2D 区域四等分，支持高效范围查询与空间粗筛。
>
> 关键词：`四叉树` `八叉树` `范围查询` `空间划分`

[← 数据结构索引](study_note/data_struct/index.html) · [AABB](md.html?file=study_note/data_struct/22_AABB包围盒.md) · [空间索引概览](md.html?file=study_note/data_struct/22_空间索引概览.md)

## 速查卡

| 项目 | 内容 |
|------|------|
| 分叉 | 2D 固定 4（NW/NE/SW/SE） |
| 3D 对应 | 八叉树 Octree，8 子节点 |
| 建树 | O(n log n) 均摊 |
| 范围查询 | O(log n + k)，k 为结果数 |
| 依赖 | [AABB](md.html?file=study_note/data_struct/22_AABB包围盒.md) 相交测试 |

---

## 定义

根节点对应一块矩形区域；若对象过多则 **四等分** 为四个子象限，递归直到满足停止条件。

### 停止条件

- 节点内对象数 ≤ `capacity`
- 或深度 ≥ `maxDepth`
- 或区域边长 < 最小阈值

## 节点与划分

```cpp
// === File: quadtree.cpp ===
#include <memory>
#include <vector>

struct Vec2 { float x, y; };
struct AABB2D { Vec2 min, max; };

struct QTObject {
    int id;
    AABB2D bounds;
};

struct QuadNode {
    AABB2D region;
    std::vector<QTObject> objects;
    std::unique_ptr<QuadNode> children[4];
    bool isLeaf = true;
};

constexpr int QT_CAPACITY = 4;
constexpr int QT_MAX_DEPTH = 8;

void subdivide(QuadNode& node) {
    Vec2 mid{(node.region.min.x + node.region.max.x) * 0.5f,
             (node.region.min.y + node.region.max.y) * 0.5f};
    const AABB2D& r = node.region;
    node.children[0] = std::make_unique<QuadNode>(AABB2D{r.min, mid});
    node.children[1] = std::make_unique<QuadNode>(AABB2D{{mid.x, r.min.y}, {r.max.x, mid.y}});
    node.children[2] = std::make_unique<QuadNode>(AABB2D{{r.min.x, mid.y}, {mid.x, r.max.y}});
    node.children[3] = std::make_unique<QuadNode>(AABB2D{mid, r.max});
    node.isLeaf = false;
}
```

## 范围查询

```cpp
bool intersects(const AABB2D& a, const AABB2D& b);

void query(const QuadNode& node, const AABB2D& range, std::vector<int>& out) {
    if (!intersects(node.region, range)) return;
    for (const auto& obj : node.objects)
        if (intersects(obj.bounds, range)) out.push_back(obj.id);
    if (!node.isLeaf)
        for (int i = 0; i < 4; ++i)
            if (node.children[i]) query(*node.children[i], range, out);
}
```

查询矩形与节点区域不相交时整棵子树剪枝。

## 与 KD-tree 对比

| | 四叉树 | KD-tree |
|---|--------|---------|
| 分叉 | 4（2D） | 2 |
| 分割位置 | 区域中心 | 中位数 / 物体中心 |
| 实现 | 直观 | 更灵活 |

## 八叉树（3D）

每个节点八等分，子索引常按 octant 编码。用于体素、3D 场景管理、点云 LOD。

---

## 典型应用

- 2D 地图分块加载
- 游戏单位区域检索（「矩形内敌人」）
- GIS 空间索引
- 物理 broad phase（均匀分布时）

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 大物体跨多格 | 存父节点或维护多格引用列表 |
| 深度无上限 | 设 `maxDepth` 防退化 |
| 对象重心划分象限 | 应以物体 AABB 与象限关系决定归属 |
| 3D 仍用四叉树 | 改用八叉树 |
