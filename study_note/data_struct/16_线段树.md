# 线段树

> **一句话**：二叉树存储区间聚合信息，支持区间查询与单点/区间修改，O(log n)。
>
> 关键词：`线段树` `区间和` `懒标记` `区间修改`

## 速查卡

| 操作 | 复杂度 |
|------|--------|
| 建树 | O(n) |
| 区间查询 [l,r] | O(log n) |
| 单点修改 | O(log n) |
| 区间修改（懒标记） | O(log n) |

适用：**多次**区间问 + 修改；单次查询用前缀和即可。

## 区间和线段树

```cpp
// === File: segment_tree.cpp ===
#include <vector>

class SegTree {
    int n_;
    std::vector<long long> tree_;

    void build(const std::vector<int>& a, int node, int l, int r) {
        if (l == r) { tree_[node] = a[l]; return; }
        int mid = l + (r - l) / 2;
        build(a, node * 2, l, mid);
        build(a, node * 2 + 1, mid + 1, r);
        tree_[node] = tree_[node * 2] + tree_[node * 2 + 1];
    }

public:
    SegTree(const std::vector<int>& a) : n_(static_cast<int>(a.size())),
        tree_(4 * n_) {
        if (n_ > 0) build(a, 1, 0, n_ - 1);
    }

    long long query(int node, int l, int r, int ql, int qr) const {
        if (ql <= l && r <= qr) return tree_[node];
        int mid = l + (r - l) / 2;
        long long res = 0;
        if (ql <= mid) res += query(node * 2, l, mid, ql, qr);
        if (qr > mid) res += query(node * 2 + 1, mid + 1, r, ql, qr);
        return res;
    }

    long long query(int l, int r) const { return query(1, 0, n_ - 1, l, r); }

    void update(int node, int l, int r, int idx, int val) {
        if (l == r) { tree_[node] = val; return; }
        int mid = l + (r - l) / 2;
        if (idx <= mid) update(node * 2, l, mid, idx, val);
        else update(node * 2 + 1, mid + 1, r, idx, val);
        tree_[node] = tree_[node * 2] + tree_[node * 2 + 1];
    }

    void update(int idx, int val) { update(1, 0, n_ - 1, idx, val); }
};
```

下标 1 为根，`[l,r]` 为节点管辖区间。

---

## 懒标记（区间加）

区间 `[ql,qr]` 整体加 `v`：若节点区间被完全覆盖，在 `lazy` 记录增量，查询时再下推。

适用：区间加、区间赋值、区间最值维护（需改写 merge）。

## 与其他结构

| 需求 | 结构 |
|------|------|
| 仅前缀和、无修改 | 前缀和 O(1) |
| 单点改 + 区间和 | 树状数组更简单 |
| 区间改 + 区间问 | 线段树 / 懒标记 |
| 动态开点 | 离散化或动态节点 |

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 数组开 4n 不够 | 一般 4n，递归深度 log n |
| 区间越界 | 查询前 clamp |
| 懒标记未下推 | query/update 前 push |
| 建树 O(n²) | 递归 build O(n) |
