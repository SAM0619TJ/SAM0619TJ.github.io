# 图

> **一句话**：顶点 + 边描述多对多关系，邻接表是竞赛与工程的首选表示。
>
> 关键词：`graph` `邻接表` `BFS` `DFS` `有向` `无向`

## 速查卡

| 项目 | 内容 |
|------|------|
| 顶点 V、边 E | 图 G = (V, E) |
| 有向 / 无向 | 边是否有方向 |
| 加权 / 无权 | 边是否有权重 |
| 邻接表 | `vector<vector<int>>`，省空间 |
| 邻接矩阵 | `vector<vector<int>>` n×n，O(1) 判边 |
| BFS | 无权最短路层数、层次遍历 |
| DFS | 连通分量、拓扑、回溯 |

---

## 问题建模

图描述**网络关系**：社交好友、城市路网、依赖关系、网格连通（可配合并查集）。

建模步骤（Sedgewick 科学方法）：

1. 确定顶点是什么（对象编号 0..N-1）
2. 确定边表示什么关系
3. 选存储结构
4. 选遍历/最短路算法

## 图的表示

### 邻接表（推荐）

```cpp
// === File: graph.cpp ===
#include <vector>

/* 无向图，n 个顶点 0..n-1 */
class Graph {
    int n_;
    std::vector<std::vector<int>> adj_;
public:
    explicit Graph(int n) : n_(n), adj_(n) {}

    void addEdge(int u, int v, bool directed = false) {
        adj_[u].push_back(v);
        if (!directed) adj_[v].push_back(u);
    }

    const std::vector<std::vector<int>>& adj() const { return adj_; }
    int size() const { return n_; }
};
```

空间 O(V + E)，遍历顶点 u 的邻居 O(deg(u))。

### 邻接矩阵

```cpp
std::vector<std::vector<int>> mat(n, std::vector<int>(n, 0));
mat[u][v] = 1;  // 有边
```

判边 O(1)，但空间 O(V²)，稀疏图浪费。

### 加权图

```cpp
std::vector<std::vector<std::pair<int,int>>> adj;  // 邻居, 权重
adj[u].emplace_back(v, w);
```

## BFS（广度优先）

用**队列**，按层扩展；**无权图**边权为 1 时求最短路步数。

```cpp
#include <queue>
#include <vector>

std::vector<int> bfs(const Graph& g, int start) {
    int n = g.size();
    std::vector<int> dist(n, -1);
    std::queue<int> q;
    dist[start] = 0;
    q.push(start);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g.adj()[u]) {
            if (dist[v] == -1) {
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }
    return dist;
}
```

## DFS（深度优先）

用**递归**或**栈**，深入到底再回溯。

```cpp
void dfs(const Graph& g, int u, std::vector<bool>& vis, std::vector<int>& order) {
    vis[u] = true;
    order.push_back(u);
    for (int v : g.adj()[u])
        if (!vis[v]) dfs(g, v, vis, order);
}

std::vector<int> dfsAll(const Graph& g, int start) {
    std::vector<bool> vis(g.size(), false);
    std::vector<int> order;
    dfs(g, start, vis, order);
    return order;
}
```

### 应用

- 统计连通分量（多次 DFS/BFS）
- 检测环（有向图三色标记）
- 拓扑排序（有向无环图）

## 遍历对比

| | BFS | DFS |
|---|-----|-----|
| 数据结构 | 队列 | 栈 / 递归 |
| 顺序 | 按层 | 深入分支 |
| 最短路（无权） | 是 | 否 |
| 空间 | 最宽层 | 递归深度 |

## 例题：岛屿数量（网格图）

将二维网格视为图，四连通分量计数：

```cpp
void flood(std::vector<std::vector<char>>& grid, int r, int c) {
    int R = static_cast<int>(grid.size()), C = static_cast<int>(grid[0].size());
    if (r < 0 || r >= R || c < 0 || c >= C || grid[r][c] == '0') return;
    grid[r][c] = '0';
    flood(grid, r + 1, c);
    flood(grid, r - 1, c);
    flood(grid, r, c + 1);
    flood(grid, r, c - 1);
}

int numIslands(std::vector<std::vector<char>>& grid) {
    int cnt = 0;
    for (int r = 0; r < static_cast<int>(grid.size()); ++r)
        for (int c = 0; c < static_cast<int>(grid[0].size()); ++c)
            if (grid[r][c] == '1') { flood(grid, r, c); ++cnt; }
    return cnt;
}
```

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 无向图只加单向边 | `addEdge` 双向或 `directed=true` |
| BFS 不标记已访问 | 入队时即标记 `dist[v]` |
| DFS 栈溢出 | 深图改迭代或限制递归深度 |
| 混淆 BFS 最短路条件 | 仅**无权**或边权全 1 |
