# 基本数据类型

> **一句话**：算法直接操作 CPU 原生类型；理解位宽与编码有助于分析空间与溢出。
>
> 关键词：`int` `char` `补码` `浮点` `UTF-8`

## 速查卡

| 类型 (C++) | 典型大小 | 范围（近似） |
|------------|----------|--------------|
| `bool` | 1 字节 | true / false |
| `char` | 1 字节 | -128 ~ 127 或 0~255 |
| `int` | 4 字节 | ±2×10⁹ |
| `long long` | 8 字节 | ±9×10¹⁸ |
| `float` | 4 字节 | 约 7 位有效数字 |
| `double` | 8 字节 | 约 15 位有效数字 |

## C++17 基本类型

```cpp
// === File: types.cpp ===
bool flag = true;
char ch = 'A';
int x = 42;
long long big = 1e18;
float f = 3.14f;
double d = 3.14159265;
```

竞赛与算法题常用 `int` / `long long`；下标、规模用 `int`，累加和、组合计数用 `long long` 防溢出。

---

## 整数编码：补码

计算机用**补码**存储有符号整数，使加减法硬件统一。

| 概念 | 说明 |
|------|------|
| 原码 | 符号位 + 绝对值 |
| 反码 | 符号位不变，其余取反 |
| 补码 | 反码 + 1（负数） |

**易记**：`int` 最小值绝对值比最大值大 1（如 -2³¹ 与 2³¹-1）。

---

## 浮点数

IEEE 754：符号位 + 指数 + 尾数。范围大但**有精度误差**。

```cpp
// 不要直接 == 比较浮点
const double eps = 1e-9;
bool equal = std::abs(a - b) < eps;
```

## 字符与字符串

- `char`：单字节字符（ASCII 子集）
- `std::string`：UTF-8 字节序列（C++ 标准未强制编码，实践中常用 UTF-8）

```cpp
#include <string>
std::string s = "Hello算法";
```

## 类型选型

| 场景 | 推荐 |
|------|------|
| 数组下标、节点编号 | `int` |
| 求和、乘法计数 | `long long` |
| 图边权（小） | `int` |
| 图边权（大） | `long long` |
| 坐标、几何 | `double` + eps |
| 键为字符串 | `std::string` |

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| `int` 乘法溢出 | 转 `long long` 再乘 |
| 浮点 `==` | 用误差范围 |
| `char` 当有符号/无符号混用 | 明确 `unsigned char` |
| 无符号减法下溢 | 注意 `size_t` 循环 |
