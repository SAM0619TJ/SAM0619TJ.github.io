# 堆

> **一句话**：完全二叉树上的序关系——大顶堆父 ≥ 子，小顶堆父 ≤ 子。
>
> 关键词：`heap` `priority_queue` `上浮` `下沉` `Top-K`

## 定义

- **完全二叉树**：除最后一层外满，最后一层从左连续填
- **大顶堆**：`parent ≥ children`
- **小顶堆**：`parent ≤ children`

下标关系（0-based）：

| 关系 | 公式 |
|------|------|
| 父节点 | `(i - 1) / 2` |
| 左子 | `2 * i + 1` |
| 右子 | `2 * i + 2` |

## STL 用法

```cpp
// === File: heap.cpp ===
#include <queue>
#include <vector>

/* 大顶堆（默认） */
std::priority_queue<int> max_heap;
max_heap.push(3);
max_heap.push(1);
max_heap.push(4);
int top = max_heap.top();  // 4
max_heap.pop();

/* 小顶堆 */
std::priority_queue<int, std::vector<int>, std::greater<int>> min_heap;

/* 自定义比较 */
auto cmp = [](int a, int b) { return a > b; };
std::priority_queue<int, std::vector<int>, decltype(cmp)> pq(cmp);
```

## 核心操作

### 上浮 siftUp

新元素放到末尾，与父比较并交换，直到满足堆性质。

```cpp
void siftUp(std::vector<int>& heap, int i) {
    while (i > 0) {
        int p = (i - 1) / 2;
        if (heap[p] >= heap[i]) break;
        std::swap(heap[p], heap[i]);
        i = p;
    }
}
```

### 下沉 siftDown

堆顶与较大子交换（大顶堆），向下直到满足堆性质。

```cpp
void siftDown(std::vector<int>& heap, int i, int n) {
    while (true) {
        int l = 2 * i + 1, r = 2 * i + 2, largest = i;
        if (l < n && heap[l] > heap[largest]) largest = l;
        if (r < n && heap[r] > heap[largest]) largest = r;
        if (largest == i) break;
        std::swap(heap[i], heap[largest]);
        i = largest;
    }
}
```

### 完整大顶堆类

```cpp
class MaxHeap {
    std::vector<int> data_;
public:
    void push(int x) {
        data_.push_back(x);
        siftUp(data_, static_cast<int>(data_.size()) - 1);
    }
    void pop() {
        if (data_.empty()) throw std::out_of_range("堆为空");
        std::swap(data_[0], data_.back());
        data_.pop_back();
        if (!data_.empty())
            siftDown(data_, 0, static_cast<int>(data_.size()));
    }
    int top() const {
        if (data_.empty()) throw std::out_of_range("堆为空");
        return data_[0];
    }
    bool empty() const { return data_.empty(); }
};
```

## 建堆 O(n)

从最后一个非叶节点 `n/2 - 1` 自底向上对每个节点 `siftDown`。

```cpp
void buildHeap(std::vector<int>& nums) {
    int n = static_cast<int>(nums.size());
    for (int i = n / 2 - 1; i >= 0; --i)
        siftDown(nums, i, n);
}
```

## Top-K 问题

求数组中第 K 大：维护**大小为 K 的小顶堆**，堆顶是 K 大中最小的。

```cpp
int findKthLargest(const std::vector<int>& nums, int k) {
    auto cmp = std::greater<int>();
    std::priority_queue<int, std::vector<int>, decltype(cmp)> pq(cmp);
    for (int x : nums) {
        pq.push(x);
        if (static_cast<int>(pq.size()) > k) pq.pop();
    }
    return pq.top();
}
```

时间 O(n log k)，空间 O(k)。

---

## 堆排序思路

1. 建大顶堆 O(n)
2. 反复：堆顶与末尾交换，缩小范围，`siftDown` → O(n log n)

## 堆排序完整流程

```cpp
void heapSort(std::vector<int>& a) {
    buildHeap(a);
    int n = static_cast<int>(a.size());
    for (int i = n - 1; i > 0; --i) {
        std::swap(a[0], a[i]);
        siftDown(a, 0, i);
    }
}
```

不稳定，原地 O(1) 额外空间（不计递归则 O(1)）。

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 下标从 1 开始混用 | 统一 0-based 公式 |
| `priority_queue` 默认小顶 | 默认是**大顶** |
| 下沉时只比左子 | 大顶堆要比两个子取较大 |
| Top-K 用大顶堆 | 第 K 大用**小顶堆**维护 K 个 |
