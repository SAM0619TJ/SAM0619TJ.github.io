# 单调栈与单调队列

> **一句话**：维护栈/队列内元素单调性，在 O(n) 内解决「下一个更大/滑动窗口最值」。
>
> 关键词：`单调栈` `单调队列` `下一个更大` `滑动窗口`

## 速查卡

| 结构 | 维护性质 | 典型题 |
|------|----------|--------|
| 单调递增栈 | 栈底到顶递增 | 下一个更大元素 |
| 单调递减栈 | 栈底到顶递减 | 下一个更小、柱状图最大矩形 |
| 单调队列 | 队首到队尾递减（求窗口 max） | 滑动窗口最大值 |

均摊 **O(n)**：每个元素最多入栈/出栈一次。

## 单调栈

### 下一个更大元素

对每个 `nums[i]`，找右侧第一个比它大的下标。

```cpp
// === File: monotonic_stack.cpp ===
#include <vector>
#include <stack>

std::vector<int> nextGreater(const std::vector<int>& nums) {
    int n = static_cast<int>(nums.size());
    std::vector<int> res(n, -1);
    std::stack<int> st;  // 存下标，对应值单调递减
    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[st.top()] < nums[i]) {
            res[st.top()] = i;
            st.pop();
        }
        st.push(i);
    }
    return res;
}
```

**模板**：当前元素比栈顶大 → 栈顶得到答案 → 弹出；最后入栈当前下标。

### 柱状图最大矩形

```cpp
int largestRectangleArea(const std::vector<int>& heights) {
    std::stack<int> st;
    int ans = 0, n = static_cast<int>(heights.size());
    for (int i = 0; i <= n; ++i) {
        int h = (i == n) ? 0 : heights[i];
        while (!st.empty() && heights[st.top()] > h) {
            int height = heights[st.top()]; st.pop();
            int width = st.empty() ? i : i - st.top() - 1;
            ans = std::max(ans, height * width);
        }
        st.push(i);
    }
    return ans;
}
```

## 单调队列

滑动窗口 `[i-k+1, i]` 的最大值，队首维护当前窗口最大下标。

```cpp
#include <deque>

std::vector<int> maxSlidingWindow(const std::vector<int>& nums, int k) {
    std::deque<int> dq;  // 存下标，值单调递减
    std::vector<int> res;
    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        while (!dq.empty() && dq.front() < i - k + 1) dq.pop_front();
        while (!dq.empty() && nums[dq.back()] < nums[i]) dq.pop_back();
        dq.push_back(i);
        if (i >= k - 1) res.push_back(nums[dq.front()]);
    }
    return res;
}
```

用 `std::deque` 两端 O(1) 操作。

## 与基础栈队列关系

| 普通 | 单调 |
|------|------|
| 任意入出 | 入栈前弹出破坏单调性的元素 |
| 解题靠模拟 | 解题靠「过期/被覆盖」批量出栈 |

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 栈存值不存下标 | 需要宽度/距离时用下标 |
| 单调方向搞反 | 求更大用递减栈（栈顶先被小元素弹出） |
| 窗口未弹出过期下标 | `front < i - k + 1` 时 pop_front |
| 复杂度算成 O(n²) | 均摊 O(n) |
