# 空间索引与加速结构

> **一句话**：用层次包围盒或空间划分把物体/三角形组织成树，把「全场景遍历」降为「对数级或局部」查询。
>
> 关键词：`四叉树` `KD-tree` `BSP` `AABB` `BVH` `光线追踪` `碰撞检测`

## 速查卡

| 结构 | 划分方式 | 典型维度 | 主要用途 |
|------|----------|----------|----------|
| 四叉树 Quadtree | 平面四等分 | 2D | 地图、粒子、2D 碰撞粗筛 |
| 八叉树 Octree | 空间八等分 | 3D | 体素、3D 场景管理 |
| KD-tree | 按轴交替二分 | 2D/3D/k-D | 最近邻、光线追踪、点云 |
| BSP-tree | 任意平面分割 | 2D/3D | 室内渲染排序、CSG |
| AABB | 轴对齐包围盒 | 2D/3D | 粗测、宽相位（broad phase） |
| BVH | 层次包围体 | 2D/3D | 光线追踪、物理引擎宽相位 |

**宽相位 broad phase**：快速排除不可能相交的对；**窄相位 narrow phase**：对候选对做精确检测。

## AABB（轴对齐包围盒）

边与坐标轴平行的盒子，用 `min` / `max` 表示。

```cpp
// === File: aabb.cpp ===
struct Vec2 { float x, y; };
struct Vec3 { float x, y, z; };

struct AABB3D {
    Vec3 min, max;
    void expand(const Vec3& p) {
        min.x = std::min(min.x, p.x); min.y = std::min(min.y, p.y); min.z = std::min(min.z, p.z);
        max.x = std::max(max.x, p.x); max.y = std::max(max.y, p.y); max.z = std::max(max.z, p.z);
    }
    void merge(const AABB3D& o) { expand(o.min); expand(o.max); }
};

struct AABB2D {
    Vec2 min, max;

    static AABB2D fromPoints(const Vec2& a, const Vec2& b) {
        return {{std::min(a.x, b.x), std::min(a.y, b.y)},
                {std::max(a.x, b.x), std::max(a.y, b.y)}};
    }

    void expand(const Vec2& p) {
        min.x = std::min(min.x, p.x); min.y = std::min(min.y, p.y);
        max.x = std::max(max.x, p.x); max.y = std::max(max.y, p.y);
    }

    void merge(const AABB2D& o) {
        expand(o.min); expand(o.max);
    }
};

bool intersects(const AABB2D& a, const AABB2D& b) {
    return a.min.x <= b.max.x && a.max.x >= b.min.x &&
           a.min.y <= b.max.y && a.max.y >= b.min.y;
}
```

3D 同理，三轴分别比较。AABB 相交测试 **O(1)**，是后续所有加速结构的基石。

### 射线与 AABB（slab 法）

沿 x/y/z 轴求射线进入/离开区间的交集：

```cpp
bool rayHitAABB(const Vec3& ro, const Vec3& rd, const AABB3D& box, float& tMin, float& tMax) {
    tMin = 0.f; tMax = 1e30f;
    for (int axis = 0; axis < 3; ++axis) {
        float o = (&ro.x)[axis], d = (&rd.x)[axis];
        float bmin = (&box.min.x)[axis], bmax = (&box.max.x)[axis];
        if (std::abs(d) < 1e-8f) {
            if (o < bmin || o > bmax) return false;
        } else {
            float t1 = (bmin - o) / d, t2 = (bmax - o) / d;
            if (t1 > t2) std::swap(t1, t2);
            tMin = std::max(tMin, t1);
            tMax = std::min(tMax, t2);
            if (tMin > tMax) return false;
        }
    }
    return true;
}
```

## 四叉树（Quadtree）

将 2D 矩形区域 **四等分**（NW/NE/SW/SE），直到满足停止条件。

### 停止条件

- 节点内对象数 ≤ 阈值 `capacity`
- 或达到最大深度 `maxDepth`
- 或区域尺寸 < 最小单元

### 节点结构

```cpp
struct QTObject {
    int id;
    AABB2D bounds;
};

struct QuadNode {
    AABB2D region;
    std::vector<QTObject> objects;
    std::unique_ptr<QuadNode> children[4];  // NW, NE, SW, SE
    bool isLeaf = true;
};

constexpr int QT_CAPACITY = 4;
constexpr int QT_MAX_DEPTH = 8;

int quadrant(const AABB2D& region, const Vec2& center) {
    Vec2 mid{(region.min.x + region.max.x) * 0.5f,
             (region.min.y + region.max.y) * 0.5f};
    if (center.x >= mid.x)
        return center.y >= mid.y ? 1 : 3;  // NE, SE
    return center.y >= mid.y ? 0 : 2;    // NW, SW
}

void subdivide(QuadNode& node) {
    Vec2 mid{(node.region.min.x + node.region.max.x) * 0.5f,
             (node.region.min.y + node.region.max.y) * 0.5f};
    const AABB2D& r = node.region;
    node.children[0] = std::make_unique<QuadNode>(AABB2D{r.min, mid});                          // NW
    node.children[1] = std::make_unique<QuadNode>(AABB2D{{mid.x, r.min.y}, {r.max.x, mid.y}}); // NE
    node.children[2] = std::make_unique<QuadNode>(AABB2D{{r.min.x, mid.y}, {mid.x, r.max.y}}); // SW
    node.children[3] = std::make_unique<QuadNode>(AABB2D{mid, r.max});                         // SE
    node.isLeaf = false;
}
```

### 范围查询

```cpp
void query(const QuadNode& node, const AABB2D& range, std::vector<int>& out) {
    if (!intersects(node.region, range)) return;
    for (const auto& obj : node.objects)
        if (intersects(obj.bounds, range)) out.push_back(obj.id);
    if (!node.isLeaf)
        for (int i = 0; i < 4; ++i)
            if (node.children[i]) query(*node.children[i], range, out);
}
```

**复杂度**：建树 O(n log n)（均摊），查询 O(log n + k)，k 为结果数。

### 典型应用

- 2D 游戏地图动态加载
- 碰撞粗筛（只查同象限邻居）
- 地理信息系统（GIS）点查询

3D 对应 **八叉树 Octree**，子节点数为 8，思想相同。

## KD-tree（K-Dimensional Tree）

每个内部节点用 **垂直或水平分割平面**（2D）或 **轴对齐平面**（3D）将空间一分为二；**交替选轴**（x → y → z → x …）。

### 与四叉树区别

| | 四叉树 | KD-tree |
|---|--------|---------|
| 分叉 | 固定 4（2D） | 固定 2 |
| 分割位置 | 区域中心 | 常按中位数 / 物体中心 |
| 优势 | 实现直观 | 更灵活、高维点集更优 |

### 建树（按中位数划分）

```cpp
struct Point2D { float x, y; int id; };

struct KDNode {
    Point2D point;
    int axis;  // 0=x, 1=y
    std::unique_ptr<KDNode> left, right;
};

std::unique_ptr<KDNode> buildKD(std::vector<Point2D>& pts, int depth, int lo, int hi) {
    if (lo > hi) return nullptr;
    int axis = depth % 2;
    int mid = lo + (hi - lo) / 2;
    std::nth_element(pts.begin() + lo, pts.begin() + mid, pts.begin() + hi + 1,
        [axis](const Point2D& a, const Point2D& b) {
            return axis == 0 ? a.x < b.x : a.y < b.y;
        });
    auto node = std::make_unique<KDNode>();
    node->point = pts[mid];
    node->axis = axis;
    node->left = buildKD(pts, depth + 1, lo, mid - 1);
    node->right = buildKD(pts, depth + 1, mid + 1, hi);
    return node;
}
```

### 最近邻搜索

沿分割轴比较距离，决定只搜一侧或两侧都要搜：

```cpp
float dist2(const Point2D& a, const Point2D& b) {
    float dx = a.x - b.x, dy = a.y - b.y;
    return dx * dx + dy * dy;
}

void nearest(const KDNode* node, const Point2D& target, const KDNode*& best, float& bestD) {
    if (!node) return;
    float d = dist2(node->point, target);
    if (d < bestD) { bestD = d; best = node; }
    int axis = node->axis;
    float diff = axis == 0 ? target.x - node->point.x : target.y - node->point.y;
    const KDNode* near = diff < 0 ? node->left.get() : node->right.get();
    const KDNode* far  = diff < 0 ? node->right.get() : node->left.get();
    nearest(near, target, best, bestD);
    if (diff * diff < bestD) nearest(far, target, best, bestD);
}
```

平均 O(log n)，最坏 O(n)（点共线等退化）。

### 典型应用

- k 近邻（k-NN）
- 光线追踪中 **事件排序**（SAH KD-tree）
- 点云、激光雷达

## BSP-tree（Binary Space Partitioning）

用**任意平面**（不限轴对齐）递归分割空间，每个节点存一个分割平面。

```
        平面 P
    前侧子树 | 后侧子树
```

### 特点

| 优点 | 缺点 |
|------|------|
| 任意朝向平面，适合墙面 | 建树复杂，平面选择影响性能 |
| 可保证绘制顺序（画家算法） | 分割可能产生大量碎片多边形 |
| CSG 布尔运算 | 动态场景更新贵 |

### 遍历与渲染顺序

视点确定后，判断在平面哪一侧：先画远侧子树，再画本节点多边形，最后画近侧——无需 Z-buffer 也能近似正确排序（静态室内场景）。

```cpp
struct Plane { Vec3 n; float d; };  // n·x + d = 0

enum Side { FRONT, BACK, ON };

Side classify(const Plane& p, const Vec3& point) {
    float v = p.n.x * point.x + p.n.y * point.y + p.n.z * point.z + p.d;
    if (v > 1e-5f) return FRONT;
    if (v < -1e-5f) return BACK;
    return ON;
}
```

现代实时渲染多用 Z-buffer + BVH，BSP 多见于老引擎、室内关卡、编辑器 CSG。

## BVH（Bounding Volume Hierarchy）

**物体层次包围盒**：叶节点存单个图元（三角形/AABB），内部节点存 **合并子节点后的包围盒**；不划分空间，而是 **划分物体集合**。

### 与四叉树 / KD-tree 对比

| | 空间划分树 | BVH |
|---|------------|-----|
| 划分对象 | 空间区域 | 物体集合 |
| 同一物体 | 可能跨多格 | 只属于一条路径 |
| 动态更新 | 较难 | 可局部重建 |
| 光线追踪 | KD-tree 也常用 | **工业主流**（OptiX、Embree） |

### 朴素建树（中点划分）

```cpp
struct BVHPrimitive {
    int id;
    AABB3D bounds;
};

struct BVHNode {
    AABB3D bounds;
    int left = -1, right = -1;  // 子节点索引，-1 表示叶
    int primStart = 0, primCount = 0;
};

std::vector<BVHNode> nodes;
std::vector<BVHPrimitive> prims;

int buildBVH(int start, int end, int depth) {
    AABB3D box = prims[start].bounds;
    for (int i = start + 1; i < end; ++i) box.merge(prims[i].bounds);

    int nodeIdx = static_cast<int>(nodes.size());
    nodes.push_back({});
    nodes[nodeIdx].bounds = box;

    int count = end - start;
    if (count <= 2) {
        nodes[nodeIdx].primStart = start;
        nodes[nodeIdx].primCount = count;
        return nodeIdx;
    }

    int axis = depth % 3;
    int mid = start + count / 2;
    std::nth_element(prims.begin() + start, prims.begin() + mid, prims.begin() + end,
        [axis](const BVHPrimitive& a, const BVHPrimitive& b) {
            float ca = ((&a.bounds.min.x)[axis] + (&a.bounds.max.x)[axis]) * 0.5f;
            float cb = ((&b.bounds.min.x)[axis] + (&b.bounds.max.x)[axis]) * 0.5f;
            return ca < cb;
        });

    nodes[nodeIdx].left = buildBVH(start, mid, depth + 1);
    nodes[nodeIdx].right = buildBVH(mid, end, depth + 1);
    return nodeIdx;
}
```

### SAH 优化（了解）

**Surface Area Heuristic**：选分割轴与位置，使

$$\text{Cost} = C_{trav} + C_{isect}\left(\frac{SA_{left}}{SA_{parent}} N_{left} + \frac{SA_{right}}{SA_{parent}} N_{right}\right)$$

最小。Blender Cycles、游戏引擎离线烘焙常用。

### 光线遍历

```cpp
struct Ray { Vec3 origin, dir; };

bool intersectBVH(int nodeIdx, const Ray& ray, float& hitT) {
    if (!rayHitAABB(ray.origin, ray.dir, nodes[nodeIdx].bounds, tMin, tMax))
        return false;
    const BVHNode& n = nodes[nodeIdx];
    if (n.primCount > 0) {
        bool hit = false;
        for (int i = 0; i < n.primCount; ++i)
            if (intersectTriangle(ray, prims[n.primStart + i], hitT)) hit = true;
        return hit;
    }
    bool h = false;
    if (n.left >= 0)  h |= intersectBVH(n.left, ray, hitT);
    if (n.right >= 0) h |= intersectBVH(n.right, ray, hitT);
    return h;
}
```

期望复杂度 O(log n)，将百万三角形场景射线求交从 O(n) 降到可实时。

## 选型指南

| 场景 | 推荐 |
|------|------|
| 2D 均匀分布点/物体范围查 | 四叉树 |
| 2D/3D 最近邻、k-NN | KD-tree |
| 室内静态关卡绘制顺序 | BSP |
| 光线追踪、路径追踪 | BVH（+ SAH） |
| 物理引擎 broad phase | 均匀网格 / 四叉树 / **动态 BVH** |
| 仅判断两物体是否可能相交 | **AABB** 测试即可 |

### 管线中的位置

```
物体 → AABB 粗测 → 空间索引（Quadtree/BVH）→ 候选对 → 窄相位（精确几何）
光线 → BVH/KD-tree 遍历 → 三角形相交 → 着色
```

## 例题思路

**矩形区域内所有敌人**：四叉树 `query(region)`。

**点击选中最近单位**：KD-tree 最近邻。

**射线拾取 3D 模型**：BVH + 叶节点三角形测试。

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 四叉树对象跨多子格 | 大物体放父节点或存多格引用 |
| KD-tree 最近邻只搜一侧 | 分割距离² < 当前最优时要搜远侧 |
| BSP 平面选不好 | 树极不平衡、多边形激增 |
| BVH 不合并子包围盒 | 内部节点 bounds 必须包住所有子节点 |
| 混淆 BVH 与 KD-tree | BVH 分**物体**；KD 分**空间** |
| AABB 当精确碰撞 | AABB 只是粗测，需 narrow phase |
