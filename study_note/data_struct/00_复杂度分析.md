# 复杂度分析

> **一句话**：用增长趋势衡量算法效率，而非绝对运行时间。
>
> 关键词：`时间复杂度` `空间复杂度` `大O` `均摊` `最坏`

## 速查卡

| 项目 | 内容 |
|------|------|
| 评价维度 | 时间效率、空间效率 |
| 分析方法 | 统计操作次数 → 取渐近上界 |
| 记号 | 大 O：$O(f(n))$ 表示不超过 $cf(n)$ 的量级 |
| 常见阶 | $O(1), O(\log n), O(n), O(n\log n), O(n^2)$ |
| 均摊 | 偶尔昂贵、多数便宜 → 分摊后仍低阶 |

---

## 为什么需要复杂度分析

实际测试受硬件、编译器、数据分布影响；**复杂度分析**消除环境差异，揭示数据规模 $n$ 增大时的增长趋势。

算法设计目标：

1. **正确性**：在规定输入范围内得到正确解
2. **效率**：时间和内存可接受

---

## 时间复杂度

### 推算步骤

1. 找到与 $n$ 相关的**基本操作**（比较、赋值、数组访问）
2. 统计操作次数关于 $n$ 的表达式
3. 保留最高阶，忽略常数和低阶项

### 常见类型

| 复杂度 | 名称 | 典型算法 |
|--------|------|----------|
| $O(1)$ | 常数 | 哈希查找（均摊）、栈顶访问 |
| $O(\log n)$ | 对数 | 二分查找、堆操作、平衡树 |
| $O(n)$ | 线性 | 遍历数组、链表 |
| $O(n \log n)$ | 线性对数 | 归并排序、堆排序 |
| $O(n^2)$ | 平方 | 冒泡排序、朴素并查集 union |
| $O(2^n)$ | 指数 | 子集枚举 |

### 三种时间

| 类型 | 含义 | 使用场景 |
|------|------|----------|
| 最坏 | 最慢情况 | **最常用**，给出性能保证 |
| 最好 | 最快情况 | 几乎不用 |
| 平均 | 随机输入期望 | 接近实际，但需假设数据分布 |

### 示例：单层循环

```cpp
// === File: complexity.cpp ===
/* 时间复杂度 O(n) */
int linear(int n) {
    int res = 0;
    for (int i = 0; i < n; ++i)
        res += i;  // n 次加法
    return res;
}
```

### 示例：嵌套循环

```cpp
/* 时间复杂度 O(n^2) */
void quadratic(int n) {
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j)
            ;  // n * n 次
}
```

## 空间复杂度

统计**额外空间**随 $n$ 的增长（通常不计输入本身）。

| 复杂度 | 典型场景 |
|--------|----------|
| $O(1)$ | 原地交换、双指针 |
| $O(n)$ | 辅助数组、哈希表 |
| $O(n)$ | 递归深度 $n$（栈帧） |
| $O(n^2)$ | 邻接矩阵 |

```cpp
/* 空间 O(n)：辅助数组 */
std::vector<int> aux(n);
```

## 均摊分析

某些操作偶尔昂贵，但频繁操作便宜，**均摊**后仍低阶。

典型例子：`std::vector::push_back` 均摊 $O(1)$（扩容时 $O(n)$，但扩容频率低）。

并查集（路径压缩 + 按秩合并）的 `find` / `union` 均摊近乎 $O(1)$，严格为 $O(\alpha(n))$。

---

## 时间与空间的权衡

| 策略 | 做法 | 例子 |
|------|------|------|
| 以空间换时间 | 多占内存，加速查询 | 哈希表、前缀和 |
| 以时间换空间 | 少占内存，重复计算 | 流式处理、原地算法 |

实践中**时间往往更宝贵**，但数据量极大时空间同样关键。

## 例题

**问**：以下函数的时间复杂度？

```cpp
int mystery(int n) {
    int i = n;
    while (i > 1) {
        i /= 2;
    }
    return 0;
}
```

**答**：循环次数约为 $\log_2 n$，时间复杂度 $O(\log n)$。

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 把 $O(2n)$ 写成 $O(2^n)$ | $2n$ 是线性，$2^n$ 是指数 |
| 小数据量时凭复杂度选算法 | 常数项可能主导，需实测 |
| 忽略均摊 | `vector` 扩容、并查集需看均摊 |
| 递归只算时间不算栈空间 | 深度 $d$ 的递归空间 $O(d)$ |
