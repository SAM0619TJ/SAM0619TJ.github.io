# 并查集（Union-Find）

> **一句话**：维护动态连通分量，支持合并集合与查询是否连通。
>
> 关键词：`union-find` `连通分量` `路径压缩` `按秩合并` `渗透`

## 速查卡

| 项目 | 内容 |
|------|------|
| 操作 | `find(p)` `unite(p,q)` `connected(p,q)` `count()` |
| 最优实现 | 按秩合并 + 路径压缩 |
| 均摊复杂度 | 单次近乎 O(1)，严格 O(α(N)) |
| 存储 | `parent[]` 森林，根自指向 |
| 典型应用 | 渗透、Kruskal、等价类 |

---

## 问题建模

**动态连通性**（Sedgewick）：

- 给定 N 个对象，编号 0 到 N-1
- `union(p, q)`：连接 p 与 q 所在分量
- `connected(p, q)`：是否存在路径连接 p 与 q

「连通」是**等价关系**：自反、对称、传递。  
**连通分量**：极大连通子集。

应用：社交网络、网络连通、像素区域、Kruskal 判环、Fortran 等价语句等。

## 抽象 API

```cpp
class UF {
public:
    explicit UF(int n);           // N 个对象
    void unite(int p, int q);     // 合并
    bool connected(int p, int q); // 是否连通
    int find(int p);              // p 所在分量代表元
    int count() const;            // 连通分量个数
};
```

### Client 示例

```cpp
int n;
std::cin >> n;
UnionFind uf(n);
while (std::cin >> p >> q) {
    if (!uf.connected(p, q)) {
        uf.unite(p, q);
        std::cout << p << " " << q << "\n";
    }
}
```

## 实现演进与代价表

| 算法 | initialize | union | find |
|------|------------|-------|------|
| Quick-Find（急切） | O(N) | **O(N)** | O(1) |
| Quick-Union（懒惰） | O(N) | O(N)† | O(N) |
| 按秩合并 | O(N) | O(log N)† | O(log N) |
| 按秩 + 路径压缩 | O(N) | ~O(1) | ~O(1) |

† 含 find 根的开销。

**Quick-Find 缺陷**：union 要改所有同 id 项，N 次 union 可达 O(N²)，大规模不可用。

**Quick-Union 缺陷**：树可能很高，find 最坏 O(N)。

---

## Quick-Find（理解用）

`id[i]` 为 i 所属分量标识；连通当且仅当 `id[p] == id[q]`。

```cpp
/* union：把 id[p] 全体改成 id[q]，O(N) */
void unite(int p, int q) {
    int pid = id_[p], qid = id_[q];
    for (int i = 0; i < n_; ++i)
        if (id_[i] == pid) id_[i] = qid;
    --count_;
}
```

---

## Quick-Union

`id[i]` 为 i 的**父节点**；**根**满足 `id[r] == r`。

```cpp
int find(int p) {
    while (p != parent_[p]) p = parent_[p];
    return p;
}
void unite(int p, int q) {
    int i = find(p), j = find(q);
    if (i == j) return;
    parent_[i] = j;
    --count_;
}
```

---

## 优化 1：按秩合并（Weighted Union）

维护 `rank_[r]`（树高上界），**小树接大树**：

```cpp
void unite(int p, int q) {
    int i = find(p), j = find(q);
    if (i == j) return;
    if (rank_[i] < rank_[j]) parent_[i] = j;
    else if (rank_[i] > rank_[j]) parent_[j] = i;
    else { parent_[j] = i; ++rank_[i]; }
    --count_;
}
```

命题：按秩合并后，任意节点深度 ≤ ⌊log₂ N⌋。

---

## 优化 2：路径压缩（Path Compression）

`find` 时让路径上节点**直接指向根**（隔代压缩）：

```cpp
int find(int p) {
    while (p != parent_[p]) {
        parent_[p] = parent_[parent_[p]];
        p = parent_[p];
    }
    return p;
}
```

## 最终 C++17 实现

```cpp
// === File: union_find.cpp ===
#include <vector>

class UnionFind {
    std::vector<int> parent_;
    std::vector<int> rank_;
    int count_;

public:
    explicit UnionFind(int n) : parent_(n), rank_(n, 0), count_(n) {
        for (int i = 0; i < n; ++i) parent_[i] = i;
    }

    int find(int p) {
        while (p != parent_[p]) {
            parent_[p] = parent_[parent_[p]];
            p = parent_[p];
        }
        return p;
    }

    bool connected(int p, int q) {
        return find(p) == find(q);
    }

    void unite(int p, int q) {
        int i = find(p), j = find(q);
        if (i == j) return;
        if (rank_[i] < rank_[j]) parent_[i] = j;
        else if (rank_[i] > rank_[j]) parent_[j] = i;
        else { parent_[j] = i; ++rank_[i]; }
        --count_;
    }

    int count() const { return count_; }
};
```

C++17 无标准库并查集，竞赛与算法课均手写此类。

## 应用：渗透（Percolation）

N×N 网格，判断 top 与 bottom 是否通过**开放格**连通。

建模：

1. 每格一个对象，编号 0..N²-1
2. 开放相邻格则 `union`
3. **虚拟源点**连顶行、**虚拟汇点**连底行
4. 渗透 ⟺ 虚拟源与虚拟汇 `connected`（一次查询）

打开新格：标记开放，与上下左右开放邻居 union（最多 4 次）。

---

## 应用：Kruskal 最小生成树

边按权排序，依次加边，若两端**不连通**则 union 并选该边。

```cpp
// 伪代码
std::sort(edges.begin(), edges.end(), by_weight);
UnionFind uf(n);
for (auto [w, u, v] : edges) {
    if (!uf.connected(u, v)) {
        uf.unite(u, v);
        mst_weight += w;
    }
}
```

## 例题

对 N=10，执行 union(4,3), union(3,8), union(6,5) 后：

- `find(4) == find(8)` → true（同一分量）
- `find(0) == find(7)` → false

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| union 不 find 根 | 必须 `find` 后再连根 |
| 只做按秩不做压缩 | 两者合用才近乎线性 |
| 用 Quick-Find 大数据 | O(N²) 不 scale |
| 渗透判 top-bottom | 用虚拟点，避免 O(N) 次 connected |
