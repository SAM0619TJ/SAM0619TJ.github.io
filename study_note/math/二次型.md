# 二次型

> **一句话**：$n$ 个变量的齐次二次多项式，可用对称矩阵唯一表示，通过配方或谱分解化为标准形。
>
> 关键词：`二次型` `标准形` `惯性定理` `配方法` `合同变换` `正定性`

[← 数学索引](study_note/math/index.html) · [公式速查](md.html?file=study_note/math/公式速查.md)

---

## 速查卡

| 项目 | 内容 |
|------|------|
| 矩阵表示 | $f(\mathbf{x})=\mathbf{x}^TA\mathbf{x}$，$A=A^T$ |
| 标准形 | $f=\lambda_1y_1^2+\cdots+\lambda_ny_n^2$（特征值或配方） |
| 合同变换 | $\mathbf{x}=P\mathbf{y}$，$A\to P^TAP$ |
| 正惯性指数 | 标准形中 $+$ 系数个数 $=A$ 的正特征值数 |
| 负惯性指数 | $-$ 系数个数 |
| 正定 | 所有特征值 $>0$ $\Leftrightarrow$ 所有顺序主子式 $>0$ |

---

## 定义

$n$ 元 **二次型**：

$$f(x_1,\ldots,x_n)=\sum_{i,j}a_{ij}x_ix_j$$

可写为矩阵形式（取 $A$ 对称，$a_{ij}=a_{ji}$）：

$$f(\mathbf{x})=\mathbf{x}^TA\mathbf{x}$$

**合同变换**：可逆变换 $\mathbf{x}=P\mathbf{y}$ 下，

$$f=\mathbf{y}^T(P^TAP)\mathbf{y}$$

新矩阵 $B=P^TAP$ 与 $A$ **合同**。

---

## 化标准形两种方法

### 方法一：正交变换（谱分解）

对称矩阵 $A=Q\Lambda Q^T$，$\mathbf{x}=Q\mathbf{y}$：

$$f=\mathbf{y}^T\Lambda\mathbf{y}=\lambda_1y_1^2+\cdots+\lambda_ny_n^2$$

系数为特征值。

### 方法二：配方法（拉格朗日）

逐变量配方，得可逆 $P$ 使 $P^TAP=\mathrm{diag}(\pm1,\ldots)$ 或一般对角形。

---

## 核心公式与定理

| 名称 | 内容 |
|------|------|
| 对称化 | $a_{ij}=\dfrac{1}{2}\dfrac{\partial^2 f}{\partial x_i\partial x_j}$，或 $A=\dfrac{A+A^T}{2}$ |
| 谱标准形 | $f=\sum\lambda_i y_i^2$，$A=Q\Lambda Q^T$ |
| 惯性定理 | 正、负惯性指数在合同变换下不变 |
| 秩 | $\mathrm{rank}(A)=$ 标准形中非零项数 |
| 正定 | $f(\mathbf{x})>0$（$\mathbf{x}\neq\mathbf{0}$）$\Leftrightarrow\lambda_i>0$ |
| 负定 | $\lambda_i<0$ |
| 不定 | 既有正又有负特征值 |
| 半正定 | $\lambda_i\ge0$ |

### 正定判定（等价）

1. 所有特征值 $>0$
2. 所有顺序主子式 $>0$（Sylvester）
3. $A=LL^T$（Cholesky 可分解）
4. $\mathbf{x}^TA\mathbf{x}>0$，$\forall\mathbf{x}\neq\mathbf{0}$

见 [正定矩阵](md.html?file=study_note/math/正定矩阵.md)。

## 例题

### 例 1：矩阵表示

$f=x_1^2+4x_1x_2+3x_2^2$

$$A=\begin{pmatrix}1&2\\2&3\end{pmatrix}$$

验证：$\mathbf{x}^TA\mathbf{x}=x_1^2+2x_1x_2+2x_1x_2+3x_2^2=f$ ✓

### 例 2：特征值标准形

$A=\begin{pmatrix}1&2\\2&3\end{pmatrix}$，特征值 $\lambda=4\pm\sqrt{17}$（一正一负 → **不定**）。

### 例 3：配方法

$f=x_1^2+2x_1x_2+x_2^2=(x_1+x_2)^2$

令 $y_1=x_1+x_2$，标准形 $f=y_1^2$，秩 1，半正定。

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 用非对称矩阵表示 | 二次型对应唯一对称 $A$ |
| 合同变换写成 $P^{-1}AP$ | 是 $P^TAP$，不是相似 |
| 配方后符号与特征值符号混淆 | 正交变换下系数为特征值；配方系数可不同但惯性相同 |
| 半正定允许 $\mathbf{x}=\mathbf{0}$ 使 $f=0$ | 正定要求 $\mathbf{x}\neq\mathbf{0}$ 时 $f>0$ |
