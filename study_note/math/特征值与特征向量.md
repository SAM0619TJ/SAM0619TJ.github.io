# 特征值与特征向量

> **一句话**：$A\mathbf{v}=\lambda\mathbf{v}$ 中，$\mathbf{v}$ 是特征向量，$\lambda$ 是特征值，描述变换在特定方向上的伸缩。
>
> 关键词：`特征值` `特征向量` `特征多项式` `对角化` `相似` `谱`

[← 数学索引](study_note/math/index.html) · [公式速查](md.html?file=study_note/math/公式速查.md)

## 速查卡

| 项目 | 内容 |
|------|------|
| 定义 | $A\mathbf{v}=\lambda\mathbf{v}$，$\mathbf{v}\neq\mathbf{0}$ |
| 特征多项式 | $p(\lambda)=\det(A-\lambda I)$ |
| 特征值 | $p(\lambda)=0$ 的根 |
| 特征子空间 | $E_\lambda=\{\mathbf{v}\mid A\mathbf{v}=\lambda\mathbf{v}\}=\mathrm{Nul}(A-\lambda I)$ |
| 对角化 | $A=PDP^{-1}$，$D$ 对角，$P$ 列向量为特征向量 |
| 迹与行列式 | $\mathrm{tr}(A)=\sum\lambda_i$，$\det(A)=\prod\lambda_i$ |

---

## 定义

对 $n\times n$ 矩阵 $A$，若存在非零向量 $\mathbf{v}$ 和标量 $\lambda$ 使得

$$A\mathbf{v}=\lambda\mathbf{v}$$

则 $\lambda$ 是 **特征值**，$\mathbf{v}$ 是 **特征向量**。

几何意义：$A$ 作用在 $\mathbf{v}$ 上只改变长度（和可能反向），不改变方向。

---

## 求解步骤

1. 解特征方程 $\det(A-\lambda I)=0$，得所有特征值 $\lambda_i$
2. 对每个 $\lambda_i$，解 $(A-\lambda_i I)\mathbf{x}=\mathbf{0}$，得特征向量
3. 若 $n$ 个线性无关特征向量可组成基，则 $A$ 可对角化

---

## 核心公式

| 名称 | 公式 |
|------|------|
| 特征多项式 | $p(\lambda)=\det(A-\lambda I)$，次数 $=n$ |
| 代数重数 | 特征值作为多项式根的重数 |
| 几何重数 | $\dim E_\lambda=\dim\mathrm{Nul}(A-\lambda I)$ |
| 对角化条件 | $n$ 个线性无关特征向量 $\Leftrightarrow A=PDP^{-1}$ |
| 相似 | $B=P^{-1}AP$，则 $A,B$ 特征值相同 |
| 幂 | $A^k=PD^kP^{-1}$ |
| 逆 | $A^{-1}=PD^{-1}P^{-1}$（特征值取倒数） |
| 迹 | $\mathrm{tr}(A)=a_{11}+\cdots+a_{nn}=\sum_{i=1}^n\lambda_i$ |
| 行列式 | $\det(A)=\prod_{i=1}^n\lambda_i$ |

### 特殊矩阵

| 矩阵类型 | 特征值特点 |
|----------|------------|
| 三角矩阵 | 对角元即特征值 |
| 对称矩阵 $A=A^T$ | 特征值全为实数，不同特征值对应特征向量正交 |
| 正交矩阵 $Q^TQ=I$ | $|\lambda|=1$ |
| 幂等 $A^2=A$ | 特征值只能是 $0$ 或 $1$ |

---

## 对角化

若 $A$ 有 $n$ 个线性无关特征向量 $\mathbf{v}_1,\ldots,\mathbf{v}_n$，对应特征值 $\lambda_1,\ldots,\lambda_n$：

$$P=[\mathbf{v}_1\ \cdots\ \mathbf{v}_n],\quad D=\mathrm{diag}(\lambda_1,\ldots,\lambda_n)$$

$$A=PDP^{-1}$$

**用途**：快速算 $A^k$、解递推、解微分方程组。

### 不可对角化时

用 **若尔当标准形**（高级）或数值方法；几何重数 $<$ 代数重数时不可对角化。

---

## 例题

### 例 1：二阶矩阵

$$A=\begin{pmatrix}4&1\\2&3\end{pmatrix}$$

特征多项式：

$$\det\begin{pmatrix}4-\lambda&1\\2&3-\lambda\end{pmatrix}=(4-\lambda)(3-\lambda)-2=\lambda^2-7\lambda+10$$

$$(\lambda-5)(\lambda-2)=0 \Rightarrow \lambda_1=5,\ \lambda_2=2$$

$\lambda=5$：$(A-5I)\mathbf{x}=\mathbf{0}$ → $\mathbf{v}_1=(1,1)^T$

$\lambda=2$：$(A-2I)\mathbf{x}=\mathbf{0}$ → $\mathbf{v}_2=(-1,2)^T$

$$P=\begin{pmatrix}1&-1\\1&2\end{pmatrix},\ D=\begin{pmatrix}5&0\\0&2\end{pmatrix}$$

### 例 2：验证迹与行列式

$\mathrm{tr}(A)=4+3=7=5+2$，$\det(A)=12-2=10=5\times2$ ✓

### 例 3：对称矩阵

$$A=\begin{pmatrix}2&1\\1&2\end{pmatrix}$$

$\lambda=3$：$\mathbf{v}_1=(1,1)^T$；$\lambda=1$：$\mathbf{v}_2=(1,-1)^T$

$\mathbf{v}_1\cdot\mathbf{v}_2=0$，正交 ✓

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 把零向量当特征向量 | 定义要求 $\mathbf{v}\neq\mathbf{0}$ |
| 特征向量差一个常数因子 | $\mathbf{v}$ 与 $c\mathbf{v}$（$c\neq0$）是同一特征向量 |
| 代数重数 $\neq$ 几何重数时硬对角化 | 检查 $\dim E_\lambda$ 是否等于重数 |
| $\det(A-\lambda I)=0$ 算错符号 | 展开时 $(-\lambda)$ 项要特别注意 |
| 认为相似矩阵特征向量相同 | 特征值相同，特征向量一般不同 |
