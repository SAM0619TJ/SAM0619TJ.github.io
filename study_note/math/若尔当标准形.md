# 若尔当标准形

> **一句话**：不可对角化矩阵的最接近「对角」的规范形，由若尔当块沿对角拼接而成。
>
> 关键词：`若尔当形` `Jordan` `若尔当块` `广义特征向量` `不可对角化`

[← 数学索引](study_note/math/index.html) · [公式速查](md.html?file=study_note/math/公式速查.md)

## 速查卡

| 项目 | 内容 |
|------|------|
| 定理 | 复数域上每个方阵 $A$ 相似于唯一（块顺序不计）若尔当形 $J$ |
| 分解 | $A=PJP^{-1}$ |
| 若尔当块 | $J_k(\lambda)$：$k\times k$ 对角为 $\lambda$，上侧对角为 1 |
| 块数 | $=$ 特征值 $\lambda$ 的几何重数 |
| 块大小和 | $=$ 特征值 $\lambda$ 的代数重数 |
| 可对角化 | 所有块均为 $1\times1$ |

---

## 定义

### 若尔当块

$k\times k$ **若尔当块** $J_k(\lambda)$：

$$J_k(\lambda)=\begin{pmatrix}\lambda&1&0&\cdots&0\\0&\lambda&1&\cdots&0\\\vdots&\vdots&\ddots&\ddots&\vdots\\0&0&\cdots&\lambda&1\\0&0&\cdots&0&\lambda\end{pmatrix}$$

- 对角线全为 $\lambda$
- 上超对角线全为 1
- 其余为 0

$J_1(\lambda)=(\lambda)$ 就是标量块。

### 若尔当标准形

$$J=\mathrm{diag}(J_{k_1}(\lambda_1),J_{k_2}(\lambda_2),\ldots,J_{k_s}(\lambda_s))$$

**若尔当定理**（代数闭域，如 $\mathbb{C}$）：每个 $n\times n$ 矩阵 $A$ 相似于唯一若尔当形 $J$（各 $\lambda$ 的块排列顺序可不同）。

---

## 与对角化的关系

| 情形 | 若尔当形 |
|------|----------|
| 可对角化 | $J$ 为对角矩阵 |
| 不可对角化 | 至少一个块 $k\ge2$ |

**不可对角化原因**：某特征值几何重数 $<$ 代数重数 → 需要「广义特征向量」补齐。

---

## 核心公式

| 名称 | 内容 |
|------|------|
| 相似分解 | $A=PJP^{-1}$ |
| 块与重数 | $\lambda$ 的若尔当块个数 $=$ 几何重数 |
| 块阶之和 | $=$ 代数重数 |
| $J_k(\lambda)^m$ | 有闭式（二项式型），用于算 $A^m$ |
| 极小多项式 | 最大若尔当块阶决定（进阶） |

### 常见 $2\times2$ 不可对角化

$$A=\begin{pmatrix}\lambda&1\\0&\lambda\end{pmatrix}=J_2(\lambda)$$

已是若尔当形。

---

## 求若尔当形思路（手算）

1. 求特征多项式，得特征值 $\lambda_i$ 及代数重数
2. 对每个 $\lambda$：求 $\dim\mathrm{Nul}(A-\lambda I)$ $=$ 几何重数 $=$ 块个数
3. 若代数重数 $>$ 几何重数，存在 $k\ge2$ 的块
4. 用广义特征向量链构造 $P$（进阶）

**本科生常用**：直接识别 $2\times2$、$3\times3$ 典型不可对角化模式。

---

## 例题

### 例 1：$2\times2$

$$A=\begin{pmatrix}3&1\\0&3\end{pmatrix}=J_2(3)$$

已是若尔当形，$P=I$。

### 例 2：$3\times3$

$$A=\begin{pmatrix}2&1&0\\0&2&1\\0&0&2\end{pmatrix}=J_3(2)$$

单一特征值 $\lambda=2$，代数重数 3，几何重数 1 → 一个 $3\times3$ 块。

### 例 3：块对角

$$A\sim\begin{pmatrix}1&1&0&0\\0&1&0&0\\0&0&3&0\\0&0&0&3\end{pmatrix}=\mathrm{diag}(J_2(1),J_1(3),J_1(3))$$

$\lambda=1$：代数 2，几何 1 → 一块 $J_2(1)$

$\lambda=3$：代数 2，几何 2 → 两块 $J_1(3)$

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 实矩阵在 $\mathbb{R}$ 上未必有实若尔当形 | 复数域上总存在；实域可能需 $2\times2$ 旋转块（进阶） |
| 块内下三角写 1 | 上超对角为 1，不是下三角 |
| 几何重数 $=$ 代数重数就能对角化 | 还需特征向量能组成全空间基 |
| 认为若尔当形唯一到排列 | 同特征值块的排列顺序可换 |
