# 线性变换

> **一句话**：保持加法和数乘的映射 $T:V\to W$；有限维空间上线性变换与矩阵一一对应。
>
> 关键词：`线性变换` `矩阵表示` `核` `像` `基变换` `复合`

## 速查卡

| 项目 | 内容 |
|------|------|
| 线性性 | $T(\mathbf{u}+\mathbf{v})=T(\mathbf{u})+T(\mathbf{v})$，$T(c\mathbf{u})=cT(\mathbf{u})$ |
| 矩阵表示 | $T(\mathbf{x})=A\mathbf{x}$，$A$ 的列是基向量像的坐标 |
| 核 $\ker(T)$ | 被映为零向量的全体：$\{\mathbf{x}\mid T(\mathbf{x})=\mathbf{0}\}$ |
| 像 $\mathrm{Im}(T)$ | 所有像的集合：$\{T(\mathbf{x})\mid\mathbf{x}\in V\}$ |
| 秩-零化度 | $\dim(\ker T)+\dim(\mathrm{Im}\,T)=\dim(V)$ |
| 复合 | $(S\circ T)(\mathbf{x})=S(T(\mathbf{x}))$，矩阵为 $BA$（先 $T$ 后 $S$） |

---

## 定义

映射 $T:V\to W$ 是 **线性变换**，若对任意 $\mathbf{u},\mathbf{v}\in V$ 和标量 $c$：

$$T(\mathbf{u}+\mathbf{v})=T(\mathbf{u})+T(\mathbf{v}),\quad T(c\mathbf{u})=cT(\mathbf{u})$$

**等价**：$T(c_1\mathbf{v}_1+\cdots+c_k\mathbf{v}_k)=c_1T(\mathbf{v}_1)+\cdots+c_kT(\mathbf{v}_k)$

### 核与像

- **核（零空间）**：$\ker(T)=\{\mathbf{x}\in V\mid T(\mathbf{x})=\mathbf{0}\}$
- **像（值域）**：$\mathrm{Im}(T)=\{T(\mathbf{x})\mid\mathbf{x}\in V\}$

对 $T(\mathbf{x})=A\mathbf{x}$：$\ker(T)=\mathrm{Nul}(A)$，$\mathrm{Im}(T)=\mathrm{Col}(A)$。

---

## 矩阵表示

### 标准基下

设 $V=\mathbb{R}^n$，$W=\mathbb{R}^m$，$\mathcal{E}=\{\mathbf{e}_1,\ldots,\mathbf{e}_n\}$ 为标准基。

矩阵 $A$ 的第 $j$ 列 $=$ $T(\mathbf{e}_j)$ 在 $W$ 中的坐标。

$$T(\mathbf{x})=A\mathbf{x}$$

### 一般基下

若 $V$ 的基为 $\mathcal{B}$，$W$ 的基为 $\mathcal{C}$，则存在矩阵 $[T]_{\mathcal{C}}^{\mathcal{B}}$ 使得：

$$[T(\mathbf{x})]_{\mathcal{C}}=[T]_{\mathcal{C}}^{\mathcal{B}}[\mathbf{x}]_{\mathcal{B}}$$

### 基变换

设 $P$ 为从基 $\mathcal{B}$ 到标准基的坐标变换矩阵，则：

$$[T]_{\text{std}}=P[T]_{\mathcal{B}}P^{-1}$$

（相似变换，见 [特征值](md.html?file=study_note/math/特征值与特征向量.md)）

## 核心公式

| 运算 | 矩阵对应 |
|------|----------|
| 复合 $S\circ T$ | $BA$（$S$ 用 $B$，$T$ 用 $A$） |
| 恒等变换 | $I$ |
| 可逆变换 | 方阵 $A$ 可逆 $\Leftrightarrow \ker(T)=\{\mathbf{0}\}$ |
| 投影到子空间 | $P=A(A^TA)^{-1}A^T$（列满秩时） |
| 秩 | $\mathrm{rank}(A)=\dim(\mathrm{Im}\,T)$ |

## 常见线性变换

| 变换 | 矩阵 / 描述 |
|------|-------------|
| 旋转（2D，角 $\theta$） | $\begin{pmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{pmatrix}$ |
| 缩放 | $\mathrm{diag}(s_1,\ldots,s_n)$ |
| 反射（关于 $x$ 轴） | $\begin{pmatrix}1&0\\0&-1\end{pmatrix}$ |
| 投影到 $x$ 轴 | $\begin{pmatrix}1&0\\0&0\end{pmatrix}$ |
| 微分 $D(p)=p'$（在多项式空间） | 在适当基下为幂次降阶矩阵 |

## 例题

### 例 1：验证线性性

$T:\mathbb{R}^2\to\mathbb{R}^2$，$T(x,y)=(2x+y,\,x-y)$。

$$T((x_1,y_1)+(x_2,y_2))=T(x_1+x_2,y_1+y_2)=(2(x_1+x_2)+(y_1+y_2),\,(x_1+x_2)-(y_1+y_2))$$

$$=T(x_1,y_1)+T(x_2,y_2)$$

数乘同理，故为线性变换。矩阵：

$$A=\begin{pmatrix}2&1\\1&-1\end{pmatrix}$$

### 例 2：求核与像

$$A=\begin{pmatrix}1&2&3\\2&4&6\end{pmatrix}$$

$\ker(A)$：解 $x_1+2x_2+3x_3=0$，维数 $2$。

$\mathrm{Im}(A)=\mathrm{Span}\{(1,2)^T\}$，维数 $1$。

验证秩-零化度：$2+1=3=\dim(\mathbb{R}^3)$ ✓

### 例 3：复合

$T$ 用 $A$，$S$ 用 $B$，则 $S(T(\mathbf{x}))=BA\mathbf{x}$。

**注意顺序**：先作用的变换写在右边。

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 含常数项的仿射映射当成线性 | $T(\mathbf{x})=A\mathbf{x}+\mathbf{b}$（$\mathbf{b}\neq\mathbf{0}$）不是线性变换 |
| 复合顺序写反 | $S\circ T$ 对应 $BA$，不是 $AB$ |
| 混淆核与像的维数 | $\dim\ker+\dim\mathrm{Im}=\dim V$（定义域维数） |
| 认为所有变换都可逆 | 投影、降秩变换不可逆 |
