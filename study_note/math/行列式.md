# 行列式

> **一句话**：方阵对应的「体积缩放因子」，也是一个可用于判可逆的标量。
>
> 关键词：`det` `行列式` `展开` `拉普拉斯` `三角矩阵`

[← 数学索引](study_note/math/index.html) · [公式速查](md.html?file=study_note/math/公式速查.md)

## 速查卡

| 项目 | 内容 |
|------|------|
| 记号 | $\det(A)$ 或 $|A|$ |
| 二阶 | $\det\begin{pmatrix}a&b\\c&d\end{pmatrix}=ad-bc$ |
| 按第 $i$ 行展开 | $\det(A)=\sum_{j=1}^{n}a_{ij}A_{ij}$ |
| 三角矩阵 | $\det(A)=\prod_{k=1}^{n}a_{kk}$ |
| 可逆判定 | $\det(A)\neq0 \Leftrightarrow A$ 可逆 |

---

## 定义

对 $n\times n$ 矩阵 $A$，行列式 $\det(A)$ 是一个数，递归定义为：

- **$n=1$**：$\det(a_{11})=a_{11}$
- **$n=2$**：$\det\begin{pmatrix}a&b\\c&d\end{pmatrix}=ad-bc$
- **$n\ge3$**：按某一行或列做拉普拉斯展开（见下）

几何直觉：$2\times2$ 行列式是两列向量张成的平行四边形有向面积；$3\times3$ 是有向体积。

---

## 核心公式

### 拉普拉斯展开

任选第 $i$ 行：

$$\det(A)=\sum_{j=1}^{n}a_{ij}A_{ij}$$

任选第 $j$ 列：

$$\det(A)=\sum_{i=1}^{n}a_{ij}A_{ij}$$

其中 $A_{ij}$ 是代数余子式，见 [余子式](md.html?file=study_note/math/余子式.md)。

### 常用性质

| 性质 | 公式 / 结论 |
|------|-------------|
| 转置 | $\det(A^T)=\det(A)$ |
| 数乘一行 | 第 $i$ 行乘 $k$ → 行列式乘 $k$ |
| 两行互换 | 行列式变号 |
| 两行相同或成比例 | $\det(A)=0$ |
| 倍加行不变 | 第 $j$ 行 $+k\times$ 第 $i$ 行，行列式不变 |
| 乘积 | $\det(AB)=\det(A)\det(B)$ |

---

## 计算步骤

1. **先看结构**：若是三角矩阵，直接乘对角元。
2. **找零多的行/列**：选含 0 最多的行或列展开，减少计算量。
3. **降阶**：用拉普拉斯展开把 $n$ 阶降为 $n-1$ 阶。
4. **二阶收尾**：最终化为 $ad-bc$。

**展开策略口诀**：有零先展开，三角直接乘，二阶用公式。

## 例题

### 例 1：二阶

$$\det\begin{pmatrix}3&1\\2&4\end{pmatrix}=3\times4-1\times2=10$$

### 例 2：三阶（按第一行展开）

$$A=\begin{pmatrix}2&1&3\\0&4&1\\1&2&2\end{pmatrix}$$

$$\det(A)=2\begin{vmatrix}4&1\\2&2\end{vmatrix}-1\begin{vmatrix}0&1\\1&2\end{vmatrix}+3\begin{vmatrix}0&4\\1&2\end{vmatrix}$$

$$=2(8-2)-1(0-1)+3(0-4)=12+1-12=1$$

### 例 3：上三角矩阵

$$\det\begin{pmatrix}1&2&3\\0&4&5\\0&0&6\end{pmatrix}=1\times4\times6=24$$

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 展开时忘记 $(-1)^{i+j}$ 符号 | 画符号棋盘，或直接用代数余子式 $A_{ij}$ |
| 把「倍加行」当成变号操作 | 倍加一行不改变行列式 |
| 三阶用萨鲁斯法则后套到四阶 | 萨鲁斯法仅适用于 $3\times3$ |
| $\det(A+B)\neq\det(A)+\det(B)$ | 行列式没有加法分配律 |
