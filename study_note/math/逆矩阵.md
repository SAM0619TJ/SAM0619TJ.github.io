# 逆矩阵

> **一句话**：$A^{-1}$ 是 $A$ 的「乘法逆元」，满足 $AA^{-1}=I$。
>
> 关键词：`逆矩阵` `可逆` `伴随矩阵` `adj` `奇异` `求逆`

[← 数学索引](study_note/math/index.html) · [公式速查](md.html?file=study_note/math/公式速查.md)

## 速查卡

| 项目 | 内容 |
|------|------|
| 定义 | $AA^{-1}=A^{-1}A=I$ |
| 可逆条件 | $\det(A)\neq0$（等价：满秩、列线性无关） |
| 伴随矩阵法 | $A^{-1}=\dfrac{1}{\det(A)}\mathrm{adj}(A)$ |
| 二阶快捷 | $\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1}=\dfrac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$ |
| 不可逆 | $\det(A)=0$ 时称 $A$ 奇异（singular） |

---

## 定义

对 $n\times n$ 矩阵 $A$，若存在矩阵 $B$ 使得

$$AB=BA=I$$

则称 $A$ **可逆**，$B$ 记为 $A^{-1}$。

---

## 可逆等价条件（方阵）

以下条件等价：

1. $\det(A)\neq0$
2. $\mathrm{rank}(A)=n$
3. $A$ 的列（行）线性无关
4. $A\mathbf{x}=\mathbf{0}$ 仅有零解
5. 对任意 $\mathbf{b}$，$A\mathbf{x}=\mathbf{b}$ 有唯一解

---

## 核心公式

### 伴随矩阵法

$$A^{-1}=\frac{1}{\det(A)}\mathrm{adj}(A)$$

其中 $\mathrm{adj}(A)=(A_{ji})^T$，$A_{ji}$ 是代数余子式。见 [余子式](md.html?file=study_note/math/余子式.md)。

### 二阶快捷公式

$$\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1}=\frac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$$

口诀：**主对角互换，副对角变号，除以行列式**。

### 运算性质

| 性质 | 公式 |
|------|------|
| 逆的逆 | $(A^{-1})^{-1}=A$ |
| 乘积 | $(AB)^{-1}=B^{-1}A^{-1}$（注意顺序） |
| 转置 | $(A^T)^{-1}=(A^{-1})^T$ |
| 数乘 | $(kA)^{-1}=\dfrac{1}{k}A^{-1}$，$k\neq0$ |
| 行列式 | $\det(A^{-1})=\dfrac{1}{\det(A)}$ |

---

## 求逆步骤（伴随矩阵法）

1. 计算 $\det(A)$，若为 0 则不可逆，停止。
2. 求每个 $A_{ij}$（代数余子式）。
3. 组成伴随矩阵 $\mathrm{adj}(A)=(A_{ji})^T$。
4. $A^{-1}=\dfrac{1}{\det(A)}\mathrm{adj}(A)$。

**实际计算**：三阶以上通常用高斯-若尔当消元（增广矩阵 $[A|I]$ 化为 $[I|A^{-1}]$）。

---

## 例题

### 例 1：二阶

$$A=\begin{pmatrix}1&2\\3&4\end{pmatrix},\quad\det(A)=4-6=-2$$

$$A^{-1}=-\frac{1}{2}\begin{pmatrix}4&-2\\-3&1\end{pmatrix}=\begin{pmatrix}-2&1\\1.5&-0.5\end{pmatrix}$$

验证：$AA^{-1}=\begin{pmatrix}1&0\\0&1\end{pmatrix}$ ✓

### 例 2：三阶（思路）

$$A=\begin{pmatrix}2&1&0\\0&1&1\\1&0&1\end{pmatrix}$$

1. $\det(A)=2(1\cdot1-1\cdot0)-1(0\cdot1-1\cdot1)+0=2+1=3\neq0$，可逆。
2. 逐个求 $A_{ij}$，组装 $\mathrm{adj}(A)$。
3. $A^{-1}=\dfrac{1}{3}\mathrm{adj}(A)$。

（完整数值计算建议用消元法验证。）

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| $(AB)^{-1}=A^{-1}B^{-1}$ | 应为 $B^{-1}A^{-1}$，顺序颠倒 |
| $\det(A)=0$ 仍硬求逆 | 先判可逆，奇异矩阵无逆 |
| 伴随矩阵忘记转置 | $(A_{ji})^T$，不是 $(A_{ij})$ |
| $(A+B)^{-1}\neq A^{-1}+B^{-1}$ | 逆矩阵没有加法分配律 |
