# 正定矩阵

> **一句话**：对称矩阵 $A$ 满足 $\mathbf{x}^TA\mathbf{x}>0$（$\mathbf{x}\neq\mathbf{0}$），特征值全正，在优化与二次型中核心。
>
> 关键词：`正定` `半正定` `负定` `Sylvester` `Cholesky` `二次型`

[← 数学索引](study_note/math/index.html) · [公式速查](md.html?file=study_note/math/公式速查.md)

---

## 速查卡

| 项目 | 内容 |
|------|------|
| 正定 (PD) | $A=A^T$ 且 $\mathbf{x}^TA\mathbf{x}>0$，$\forall\mathbf{x}\neq\mathbf{0}$ |
| 半正定 (PSD) | $\mathbf{x}^TA\mathbf{x}\ge0$ |
| 负定 | $\mathbf{x}^TA\mathbf{x}<0$ |
| 特征值判定 | PD $\Leftrightarrow$ 所有 $\lambda_i>0$ |
| Sylvester | PD $\Leftrightarrow$ 所有顺序主子式 $>0$ |
| Cholesky | PD $\Leftrightarrow\exists$ 可逆下三角 $L$，$A=LL^T$ |

---

## 定义

对称矩阵 $A\in\mathbb{R}^{n\times n}$：

| 类型 | 定义 |
|------|------|
| **正定** | $\mathbf{x}^TA\mathbf{x}>0$，$\forall\mathbf{x}\neq\mathbf{0}$ |
| **半正定** | $\mathbf{x}^TA\mathbf{x}\ge0$ |
| **负定** | $\mathbf{x}^TA\mathbf{x}<0$，$\forall\mathbf{x}\neq\mathbf{0}$ |
| **不定** | 既非半正定也非半负定 |

---

## 等价条件（正定）

以下条件对对称 $A$ 等价：

1. 所有特征值 $\lambda_i>0$
2. 所有**顺序**主子式 $>0$（Sylvester 准则）
3. 存在可逆下三角 $L$ 使 $A=LL^T$（Cholesky）
4. 存在可逆 $P$ 使 $A=P^TP$
5. 所有主子式 $>0$（更强）
6. 二次型 $\mathbf{x}^TA\mathbf{x}$ 正定

---

## 核心公式

| 名称 | 公式 |
|------|------|
| 二次型 | $f(\mathbf{x})=\mathbf{x}^TA\mathbf{x}$ |
| 谱分解 | $A=Q\Lambda Q^T$，$\lambda_i>0$ |
| 逆 | $A^{-1}$ 也正定（若 $A$ 正定） |
| 和 | $A,B$ 正定 $\Rightarrow A+B$ 正定 |
| 乘积 | $AB$ 一般不对称，未必正定 |
| $A^TA$ | 恒半正定；$\mathrm{rank}(A)=n$ 时正定 |
| 顺序主子式 | $\Delta_k=\det(A_{1:k,1:k})>0$ |

---

## 例题

### 例 1：Sylvester 判定

$$A=\begin{pmatrix}2&-1\\-1&2\end{pmatrix}$$

$\Delta_1=2>0$，$\Delta_2=4-1=3>0$ → **正定**。

### 例 2：特征值

同上，$\lambda=1,3>0$ → 正定 ✓

### 例 3：半正定非正定

$$A=\begin{pmatrix}1&1\\1&1\end{pmatrix}$$

$\lambda=0,2$，半正定；$\mathbf{x}=(1,-1)^T$ 使 $\mathbf{x}^TA\mathbf{x}=0$ → 非正定。

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 非对称矩阵讨论正定 | 先对称化 $\dfrac{A+A^T}{2}$ |
| 所有主子式 $>0$ 与顺序主子式混淆 | Sylvester 只要求**顺序**主子式 |
| $A,B$ 正定则 $AB$ 正定 | 一般不成立 |
| 特征值为正但矩阵非对称 | 正定要求对称（实数域标准定义） |
