# 矩阵的秩

> **一句话**：矩阵列（或行）中线性无关向量的最大个数，衡量「有效信息量」。
>
> 关键词：`秩` `rank` `行阶梯形` `主元` `满秩` `秩-零化度`

[← 数学索引](study_note/math/index.html) · [公式速查](md.html?file=study_note/math/公式速查.md)

## 速查卡

| 项目 | 内容 |
|------|------|
| 定义 | $\mathrm{rank}(A)=$ 行阶梯形中主元个数 |
| 等价定义 | 列秩 $=$ 行秩 $=$ 最大无关列（行）数 |
| 范围 | $0\le\mathrm{rank}(A)\le\min(m,n)$ |
| 满列秩 | $\mathrm{rank}(A)=n$（$m\times n$）→ 列无关 |
| 满行秩 | $\mathrm{rank}(A)=m$ → 行无关 |
| 秩-零化度 | $\mathrm{rank}(A)+\mathrm{nullity}(A)=n$ |

---

## 定义

$m\times n$ 矩阵 $A$ 的 **秩** $\mathrm{rank}(A)$ 是其列空间 $\mathrm{Col}(A)$ 的维数。

**重要定理**：列秩 $=$ 行秩，故可统一称为秩。

几何/代数意义：线性变换 $A\mathbf{x}$ 的输出维数（像的维数）。

---

## 求秩步骤

1. 对 $A$ 做初等**行**变换化为行阶梯形（REF）
2. 数非零行的主元（leading entry）个数 $= \mathrm{rank}(A)$

**不必**化为行最简形，阶梯形即可。

---

## 核心公式

| 名称 | 公式 / 结论 |
|------|-------------|
| 秩-零化度 | $\mathrm{rank}(A)+\dim\mathrm{Nul}(A)=n$ |
| 乘积 | $\mathrm{rank}(AB)\le\min(\mathrm{rank}(A),\mathrm{rank}(B))$ |
| 和 | $\mathrm{rank}(A+B)\le\mathrm{rank}(A)+\mathrm{rank}(B)$ |
| 转置 | $\mathrm{rank}(A^T)=\mathrm{rank}(A)$ |
| 可逆 | $n$ 阶方阵可逆 $\Leftrightarrow\mathrm{rank}(A)=n$ |
| 方程组唯一解 | $\mathrm{rank}(A)=\mathrm{rank}([A|b])=n$ |
| 子矩阵 | $\mathrm{rank}(A)\ge$ 任意非零子式的阶数 |

### 四个子空间维数（$m\times n$）

| 子空间 | 维数 |
|--------|------|
| $\mathrm{Col}(A)\subseteq\mathbb{R}^m$ | $r$ |
| $\mathrm{Row}(A)\subseteq\mathbb{R}^n$ | $r$ |
| $\mathrm{Nul}(A)\subseteq\mathbb{R}^n$ | $n-r$ |
| $\mathrm{Nul}(A^T)\subseteq\mathbb{R}^m$ | $m-r$ |

$r=\mathrm{rank}(A)$。

## 例题

### 例 1

$$A=\begin{pmatrix}1&2&3\\2&4&6\\1&1&1\end{pmatrix}$$

$R_2\leftarrow R_2-2R_1$，$R_3\leftarrow R_3-R_1$：

$$\begin{pmatrix}1&2&3\\0&0&0\\0&-1&-2\end{pmatrix}$$

两行有主元，$\mathrm{rank}(A)=2$。

### 例 2：秩与解

$A$ 为 $3\times3$，$\mathrm{rank}(A)=2$。

- $A\mathbf{x}=\mathbf{0}$：零空间维数 $3-2=1$，一条自由变量
- 若 $\mathrm{rank}([A|b])=2$：无穷多解
- 若 $\mathrm{rank}([A|b])=3$：无解

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 把行数当成秩 | 秩 $\le\min(m,n)$，可能更小 |
| 用列变换求秩（手算时混用） | 标准做法：只用行变换 |
| 忘记秩 $=$ 主元个数 | 阶梯形中非零行数 $=$ 主元数 |
| $\mathrm{rank}(AB)=\mathrm{rank}(A)\mathrm{rank}(B)$ | 一般不成立，只有不等式 |
