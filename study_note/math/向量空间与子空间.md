# 向量空间与子空间

> **一句话**：在加法和数乘下封闭的向量集合；子空间是包含零向量、对线性组合封闭的子集。
>
> 关键词：`向量空间` `子空间` `基` `维数` `线性无关` `张成` `秩`

## 定义

### 向量空间

设 $V$ 是非空集合，$\mathbb{F}$ 为数域（通常为 $\mathbb{R}$ 或 $\mathbb{C}$）。若 $V$ 上定义了加法和数乘，且满足封闭性、结合律、交换律、零元、逆元、数乘分配律等公理，则称 $V$ 为 **$\mathbb{F}$ 上的向量空间**。

$\mathbb{R}^n$：所有 $n$ 维实列向量，按分量加法和数乘。

### 子空间

$W\subseteq V$ 是 **子空间**，当且仅当：

1. $\mathbf{0}\in W$
2. $\mathbf{u},\mathbf{v}\in W \Rightarrow \mathbf{u}+\mathbf{v}\in W$
3. $\mathbf{u}\in W,\,c\in\mathbb{F} \Rightarrow c\mathbf{u}\in W$

**等价一句话**：$W$ 对线性组合封闭且含零向量。

### 张成、线性无关、基

- **张成**：$\mathrm{Span}\{\mathbf{v}_1,\ldots,\mathbf{v}_k\}=\{c_1\mathbf{v}_1+\cdots+c_k\mathbf{v}_k\}$
- **线性无关**：仅平凡组合得零向量
- **基**：既线性无关又张成 $V$；$V$ 中每个向量可**唯一**写成基的线性组合

## 核心公式与定理

| 名称 | 内容 |
|------|------|
| 维数公式 | 若 $\{\mathbf{v}_1,\ldots,\mathbf{v}_k\}$ 线性无关，可扩充为基；基向量数 $=\dim(V)$ |
| 子空间维数 | $\dim(W)\le\dim(V)$ |
| 秩-零化度定理 | $\mathrm{rank}(A)+\mathrm{nullity}(A)=n$（$A$ 为 $m\times n$） |
| 四个基本子空间 | $\mathrm{Col}(A)\subseteq\mathbb{R}^m$，$\mathrm{Row}(A)\subseteq\mathbb{R}^n$，$\mathrm{Nul}(A)\subseteq\mathbb{R}^n$，$\mathrm{Nul}(A^T)\subseteq\mathbb{R}^m$ |

### 矩阵对应的子空间

| 子空间 | 定义 | 维数 |
|--------|------|------|
| 列空间 $\mathrm{Col}(A)$ | $A$ 各列的线性组合 | $\mathrm{rank}(A)$ |
| 零空间 $\mathrm{Nul}(A)$ | $A\mathbf{x}=\mathbf{0}$ 的解集 | $n-\mathrm{rank}(A)$ |
| 行空间 $\mathrm{Row}(A)$ | $A$ 各行（作为 $\mathbb{R}^n$ 中向量）的张成 | $\mathrm{rank}(A)$ |
| 左零空间 $\mathrm{Nul}(A^T)$ | $A^T\mathbf{y}=\mathbf{0}$ 的解集 | $m-\mathrm{rank}(A)$ |

## 子空间判定步骤

判断 $W$ 是否为子空间：

1. 零向量是否在 $W$ 中？
2. 任取 $\mathbf{u},\mathbf{v}\in W$，$\mathbf{u}+\mathbf{v}$ 是否仍在 $W$？
3. 任取 $\mathbf{u}\in W$ 和标量 $c$，$c\mathbf{u}$ 是否仍在 $W$？

**快捷否定**：若 $W$ 不过原点（不含 $\mathbf{0}$），则不是子空间。

## 例题

### 例 1：判断子空间

$W=\{(x,y,z)\mid x+y+z=1\}$ 是否为 $\mathbb{R}^3$ 的子空间？

$(0,0,0)$ 不满足 $x+y+z=1$，故 **不是** 子空间。

$W'=\{(x,y,z)\mid x+y+z=0\}$：过原点且对线性组合封闭，**是** 子空间。

### 例 2：求维数

$\mathbf{v}_1=(1,2,0)^T,\ \mathbf{v}_2=(2,4,0)^T$。$\mathbf{v}_2=2\mathbf{v}_1$，线性相关。

$\mathrm{Span}\{\mathbf{v}_1,\mathbf{v}_2\}$ 的维数为 $1$，基可取 $\{\mathbf{v}_1\}$。

### 例 3：秩-零化度

$$A=\begin{pmatrix}1&2&3\\2&4&6\end{pmatrix}$$

第二行是第一行的 2 倍，$\mathrm{rank}(A)=1$，$n=3$。

$$\mathrm{nullity}(A)=3-1=2$$

零空间是平面（二维），例如 $\mathbf{x}_1+2\mathbf{x}_2+3\mathbf{x}_3=0$ 的解集。

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 把不过原点的平面当成子空间 | 子空间必须含 $\mathbf{0}$ |
| 混淆「张成」与「基」 | 张成集未必线性无关；基必须无关 |
| $\dim(\mathbb{R}^n)=n$ 与矩阵行数混淆 | 维数是基向量个数，不是方程个数 |
| 认为 $\mathrm{Col}(A)$ 与 $\mathrm{Row}(A)$ 是同一空间 | 前者在 $\mathbb{R}^m$，后者在 $\mathbb{R}^n$（当 $m\neq n$） |
