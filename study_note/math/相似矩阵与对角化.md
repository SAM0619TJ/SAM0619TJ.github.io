# 相似矩阵与对角化

> **一句话**：$B=P^{-1}AP$ 表示同一线性变换在不同基下的矩阵；对角化即选特征向量作基。
>
> 关键词：`相似` `对角化` `特征向量` `过渡矩阵` `可对角化`

## 速查卡

| 项目 | 内容 |
|------|------|
| 相似 | $B=P^{-1}AP$，$P$ 可逆 |
| 对角化 | $A=PDP^{-1}$，$D$ 对角 |
| 可对角化条件 | $n$ 个线性无关特征向量（几何重数之和 $=n$） |
| 不变量 | 特征值、秩、迹、行列式在相似下不变 |
| 对称矩阵 | 必可正交对角化 $A=Q\Lambda Q^T$ |
| 不可对角化 | 转向 [若尔当标准形](md.html?file=study_note/math/若尔当标准形.md) |

---

## 定义

### 相似矩阵

若存在可逆矩阵 $P$ 使得

$$B=P^{-1}AP$$

则称 $A$ 与 $B$ **相似**。

意义：$A,B$ 是同一线性变换在不同基下的矩阵表示。

### 对角化

若 $D$ 为对角矩阵且

$$A=PDP^{-1}$$

则 $A$ **可对角化**。$P$ 的列是特征向量，$D$ 对角元是特征值。

---

## 可对角化判定

$n\times n$ 矩阵 $A$ 可对角化 $\Leftrightarrow$ 以下等价之一成立：

1. 有 $n$ 个线性无关的特征向量
2. 每个特征值的**几何重数** $=$ **代数重数**
3. $A$ 的极小多项式无重根（进阶）

**充分条件**：$n$ 个不同特征值 → 特征向量无关 → 可对角化。

---

## 核心公式

| 名称 | 公式 |
|------|------|
| 相似 | $B=P^{-1}AP$ |
| 对角化 | $A=PDP^{-1}$，$A^k=PD^kP^{-1}$ |
| 不变量 | $\det,\mathrm{tr},\mathrm{rank},\text{特征值}$ 相似不变 |
| 对称矩阵 | $A=A^T\Rightarrow A=Q\Lambda Q^T$，$Q$ 正交 |
| 过渡矩阵 | $[T]_{\mathcal{B}}=P^{-1}[T]_{\mathcal{C}}P$ |

---

## 对角化步骤

1. 求特征值 $\lambda_i$
2. 对每个 $\lambda_i$ 求特征向量，组成 $\mathbf{v}_1,\ldots,\mathbf{v}_n$
3. 验证 $P=[\mathbf{v}_1\cdots\mathbf{v}_n]$ 可逆（列无关）
4. $D=\mathrm{diag}(\lambda_1,\ldots,\lambda_n)$，$A=PDP^{-1}$

---

## 例题

### 例 1：可对角化

$$A=\begin{pmatrix}2&1\\0&3\end{pmatrix}$$

上三角，$\lambda_1=2,\lambda_2=3$，不同特征值必可对角化。

$\mathbf{v}_1=(1,0)^T$，$\mathbf{v}_2=(1,1)^T$

$$P=\begin{pmatrix}1&1\\0&1\end{pmatrix},\ D=\begin{pmatrix}2&0\\0&3\end{pmatrix}$$

### 例 2：不可对角化

$$A=\begin{pmatrix}2&1\\0&2\end{pmatrix}$$

$\lambda=2$ 代数重数 2，但 $(A-2I)\mathbf{x}=\mathbf{0}$ 仅得 $\mathbf{v}=(1,0)^T$，几何重数 1。

不可对角化，需若尔当形。

---

## 易错点

| 易错 | 正确做法 |
|------|----------|
| 有特征值就能对角化 | 需足够无关特征向量 |
| $P$ 列顺序与 $D$ 对角元不对应 | 第 $j$ 列特征向量对应 $D_{jj}=\lambda_j$ |
| 相似 $=$ 相等 | 相似是 $P^{-1}AP$，不是 $A=B$ |
| 非对称矩阵用 $Q^T=Q^{-1}$ 对角化 | 一般 $P$ 不必正交 |
