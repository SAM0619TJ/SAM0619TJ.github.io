## 常用 GLSL 片段

### Lambert 漫反射

```glsl
float NdotL = max(dot(n, l), 0.0);
vec3 color = albedo * lightColor * NdotL;
```

### smoothstep 边缘

```glsl
float edge = smoothstep(0.0, 0.01, sd);
```

### Raymarching 主循环骨架

```glsl
float t = 0.0;
for (int i = 0; i < 64; i++) {
    vec3 p = ro + rd * t;
    float d = map(p);
    if (d < 0.001) break;
    t += d;
}
```
