# blog_prime

个人网站 + 个人笔记仓库（按主题分目录整理）。

## 入口

- `orgin.html`：网站主页（静态单页）

## 本地预览

在仓库根目录运行：

```bash
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000/orgin.html`。

## 目录结构

- `diary/`：日记
- `hobbies/`：兴趣
- `life_goals/`：目标/计划
- `robot_engineering/`：机器人/嵌入式相关记录
- `study_note/`：学习笔记（数学、Shader、命令行等）
- `study_note/math/`：线性代数笔记索引
- `study_note/shader/`：GLSL / 图形着色器笔记索引
- `study_note/data_struct/`：数据结构笔记索引（C++17）
